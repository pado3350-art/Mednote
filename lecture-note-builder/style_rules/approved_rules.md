## 사용자가 승인한 학습 규칙 (저장소 v26)
사용자가 직접 고친 강의록에서 뽑아 **승인한** 규칙이다. 다른 문체 규칙과 충돌하면 이쪽이 우선한다. 단, 파랑 = 기출(PAD) 전용 규칙과 내용 보존(수치·용어·출처) 규칙은 그대로 지킨다.

- **L1 v1** [문체 · 적용: 모든 강의] 한 줄에 한 사실만 쓴다(목표 45자 이하). 사실을 줄표(—)·가운뎃점(·)으로 잇지 않고 조사·연결어미로 쓴다. 화살표(→)는 인과·순서에만 쓴다.
  - 전: MIA 골관절염 동물 모델 무릎에 분리한 미토콘드리아를 넣었더니 연골이 많이 개선 — 세포가 에너지를 받아 분화·이동이 빨라지고, 연골 덩어리 제작에도 도움
    후: 교수님 연구팀은 mitochondria를 분리해 골관절염 동물 모델(MIA)의 무릎에 투여했다. / 대조군보다 연골 손상이 개선되었다.
- **L2 v1** [구성 · 적용: 모든 강의] 표·가로 비교 칸 앞에 도입문 1줄("~로 나누면 다음과 같다")을 두고, 세부 설명 뒤에는 "즉 …" 정리문 1줄을 쓴다.
  - 전: (소제목 바로 뒤에 표)
    후: 줄기세포를 분화능에 따라 분류하면 다음과 같다. → 표
  - 전: (정리문 없음)
    후: 즉 조직학적으로 좋은 것은 스페로이드 제형이나 practical하게 좋은 것은 single cell이므로 둘 사이의 중용이 필요하다.
- **L3 v1** [구성 · 적용: 모든 강의] 절 끝에서 다음 절로 넘어가는 인과 다리 문장("~ 때문에 ~ 시도가 이루어졌다")은 강의 논리를 잇기만 하면 본문 문장으로 쓴다(회색 작성자 괄호가 아님).
  - 전: (ESC는 윤리 문제, MSC는 한계 — 그래서 연자팀은 iPSC에 집중한다.)  ← 회색 괄호
    후: 따라서 각각의 한계 때문에 교수님 연구팀은 iPSC에 집중한다.  ← 본문
- **L4 v1** [구성 · 적용: 모든 강의] 연구·실험 서사는 방법 → 결과 → 의미 3단으로 쓴다. 결과는 줄마다 한 절, 과거형으로 쓰고 "즉 …"으로 의미를 맺는다.
  - 전: 연구에서 … 투여 → 개선, iPSC 유래가 더 효과 (한 줄)
    후: 연구에서는 mitochondria를 분리해 무릎에 투여하였더니 / 대조군에 비해 연골 손상이 개선되었고 / iPSC 유래가 더 효과가 좋았다. / 즉 …
- **L5 v2** [문체 · 적용: 모든 강의] 설명 문단, 질문 상자의 ‘A.’ 답, 핵심 답, 작성자 메모는 모두 합니다체로 쓴다(‘~합니다/~입니다’). 표 칸은 개조식(L19), 제목·라벨은 명사형, 개념 Check·QUIZ의 O/X·보기 문장은 시험 문장 형태(한다체)를 유지한다. 교수님 발언 인용형은 쓰지 않는다(L6). (v2: 한다체 → 합니다체(사용자 지시). v1은 ‘내용은 한다체, 메모만 합니다체 괄호’였다. L19의 ‘설명 문단과 A. 줄은 한다체’는 이 규칙이 대체함.)
  - 전: 약이 균이 있는 곳에 충분히 닿아야 하므로 기관마다 약과 경로를 바꾼다.
    후: 약이 균이 있는 곳에 충분히 닿아야 하므로 기관마다 약과 경로를 바꿉니다.
- **L6 v1** [문체 · 적용: 모든 강의] 교수님 말을 인용하는 형태("교수님은 ~라고 하셨다")는 계속 쓰지 않는다. 다만 교수 본인의 연구임을 밝힐 때는 "교수님 연구(팀)"이라고 쓴다. "연자"라는 말은 쓰지 않는다. (my-writing-style 규칙 1의 범위를 좁힘(인용형만 금지))
  - 전: 연자팀은 iPSC allo를 택했다
    후: 교수님 연구팀은 iPSC allo를 택했다
- **L7 v1** [용어 · 적용: 모든 강의] 용어는 슬라이드의 영문 표기를 우선한다(mitochondria, spheroid, organoid, ECM). 음성 변환 음차는 처음 한 번만 괄호로 병기한다.
  - 전: 미토콘드리아
    후: mitochondria(미토콘드리아)
- **L8 v1** [설명 깊이 · 적용: 모든 강의] 일화·개인사·장식 수치는 회색 글씨로 짧게 남긴다. 결론·비교를 뒷받침하는 수치와 통계 조건("~에서만", "경계 수준")은 일반 글씨로 남긴다. 아주 사소하고 기출에 한 번도 나온 적 없는 것은 뺀다(뺀 수치는 meta.omitted에 적어 검증기에 알린다). (사용자 수정: 생략 대신 회색, 아주 사소+기출 없음만 삭제)
  - 전: Neuronata-R … 2,000억 원 이상 투입, 주가 10분의 1
    후: {g|코아스템켐온 주가 10분의 1, 2,000억 원 이상 투입}
  - 전: 국정감사 참고인 출석, 주주 비판
    후: (삭제 — 사소하고 기출에 없음)
- **L9 v1** [설명 깊이 · 적용: 모든 강의] 사례(제품·기관·인물)는 "이름(영문): 한 줄"로 쓰고, 경위·부가 설명은 회색 글씨로 붙인다. 아주 사소하고 기출에 없는 사례는 뺀다. (사용자 수정: 부가 설명은 회색)

    후: 카티스템(Cartistem): 메디포스트의 제대혈 유래 MSC 치료제 {g|— 수술로 주입}
- **L10 v1** [구성 · 적용: 모든 강의] 혼합형을 기본으로 쓴다. 개념·기전·원리·‘왜’를 다루는 소절은 설명형(질문형 제목 + 한 줄 핵심 답 + 추론 문단), 수치·사례·제품·실험 결과·절차·분류 소절은 나열형(도입문 1줄 + bullet/표 + ‘즉 …’ 1줄)으로 쓴다. 템플릿 mom_mixed.yaml, Topic.style=explain|list. (사용자 지시: '혼합형을 기본 규칙으로 설정해줘' (2026-11-10))

    후: (설명형) 왜 골관절염에 재생 치료가 필요한가? → 핵심 답 1줄 → 문단 / (나열형) MSC 골관절염 RCT 결과 → **대상**: … / **통증**: … / 즉 …
