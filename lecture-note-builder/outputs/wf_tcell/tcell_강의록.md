## 1장. MHC(HLA) 유전자 영역의 구성

<a name="topic-3"></a>

### 1. MHC 유전자는 어디에 있고 어떻게 나뉘나?

**핵심 답**

- 6번 염색체의 HLA 영역이고, class I, II, III로 나눕니다.


사람의 MHC 유전자는 6번 염색체에 있고, 흔히 HLA(human leukocyte antigen)라고 부릅니다. 이 영역에 여러 유전자가 밀집해 있어 class I, class II, class III 영역으로 구분해서 봅니다.


![인간 HLA와 생쥐 H-2의 유전자 구조 (슬라이드)](../../inputs/tcell_figs/f_gene.png)


위의 그림이 인간(HLA, 6번 염색체), 아래 그림이 생쥐(H-2, 17번 염색체)의 MHC 영역입니다.



<a name="topic-4"></a>

### 2. class I과 class II에는 어떤 분자가 있나?

- ‘MHC class II 분자’를 묻는지 ‘class II region에 있는 유전자’를 묻는지 구분해서 읽어야 하고, 이름을 외우기보다 유전자 영역과 실제 분자의 기능을 구분하는 것이 중요하다고 강조하셨습니다.
- **개념 Check** HLA-DR은 MHC class II에 해당한다. (O, X) → O — class II는 HLA-DR, DP, DQ이다.
- **개념 Check** HLA-E는 CD8 T세포에 바이러스 항원을 제시하는 고전적 class I 분자이다. (O, X) → X — 고전적 class I은 HLA-A, B, C이고 HLA-E, F, G는 class Ib이다.


<a name="topic-5"></a>

### 3. 유전자 영역 안에는 또 무엇이 있나?


![확대한 MHC 유전자 지도: class II, III, I 영역 (슬라이드)](../../inputs/tcell_figs/f_map.png)

- 그림은 위아래로 나뉘어 있지만 길게 연결된 하나의 영역입니다. class I, class II 유전자만 모여 있는 것이 아니라, 사이사이에 항원을 가공하고 제시하는 유전자가 있습니다.
- 하나의 영역에 면역 관련 유전자가 함께 모여 있다는 점이 뒤에서 면역 반응이 함께 조절된다는 설명으로 이어집니다.


<a name="topic-6"></a>

### 4. 면역 반응에서 MHC 유전자 발현은 어떻게 조절되나?

**핵심 답**

- interferon이 발현을 조절하고, class II는 CIITA가 중요합니다.


감염이 생기면 여러 면역 관련 유전자의 발현이 변합니다. 강의 자료는 interferon alpha, beta, gamma가 MHC 관련 유전자 발현을 조절한다고 제시하고, 그 결과 감염된 세포가 바이러스 단백질 유래 peptide를 제시할 기회가 늘어납니다.


class II의 전사 조절에는 CIITA라는 co-activator가 중요하고, interferon-gamma는 class II 관련 유전자 발현과 연결해 기억합니다.


모든 조절 경로를 외울 필요는 없고, 항원제시 분자만 따로 만들어지는 것이 아니라 가공과 제시에 필요한 구성요소가 함께 조절된다는 큰 흐름을 잡으면 됩니다.

## 2장. MHC의 다양성: polymorphism과 polygeny

<a name="topic-7"></a>

### 1. MHC는 왜 여러 종류가 있어야 하나?

**핵심 답**

- 한 종류면 회피 돌연변이가 모든 사람에게 통하기 때문입니다.


감염원의 입장에서 보면, 자기 단백질 조각이 MHC에 얹혀 T세포에 보이면 면역계가 자신을 알아보게 되므로 그 경로를 피하고 싶어 합니다.


그런데 사람에게 MHC가 한 종류뿐이라면, 그 결합을 피하는 돌연변이가 생겼을 때 모든 사람에게 통할 가능성이 커집니다. 실제로는 한 사람 안에서도 여러 MHC 유전자가 발현되고, 사람 사이에는 allele의 종류가 아주 다양합니다. 이 두 가지가 오늘의 중요한 출발점입니다.



<a name="topic-8"></a>

### 2. polygeny와 polymorphism은 무엇이 다른가?


![polymorphism, polygeny, 그리고 둘이 함께 있는 경우 (슬라이드)](../../inputs/tcell_figs/f_poly_types.png)

- ‘한 개체의 유전자 수가 많다’와 ‘집단 전체의 allele 종류가 많다’를 바꿔 쓰지 말고 반드시 구분해서 이해하라고 강조하셨습니다.


<a name="topic-9"></a>

### 3. 어느 MHC 분자가 가장 다양한가?

- 다형성은 모든 MHC 분자에서 똑같이 큰 것이 아니라 고전적 class I 쪽이 크고 class Ib에서는 상대적으로 제한적입니다. 최신 allele 개수까지 외우기보다 상대적인 경향과 기능을 먼저 이해합니다.
- class II에서는 다형성이 beta chain 쪽에 집중되어 있습니다. 다형성이 peptide가 들어가는 결합 부위와 관련되어 있어서, 같은 감염원의 peptide라도 사람의 MHC 종류에 따라 결합 가능성이 달라집니다.
- **개념 Check** Class I 중 다형성이 가장 높은 유전자좌는 HLA-A이다. (O, X) → X — HLA-B이다 (B > A > C).
- **개념 Check** Class II 중 가장 polymorphic한 것은 HLA-DR(DRB)이다. (O, X) → O — DRB > DQB > DPB이다.


<a name="topic-10"></a>

### 4. 다양성은 어디서 생기고 무엇을 바꾸나?

**핵심 답**

- gene conversion으로 생기고, peptide 결합 부위를 바꿉니다.


다양성의 중요한 기전은 gene conversion입니다. 서로 비슷한 서열의 유전자 사이에서 유전정보 일부가 바뀌면 원래와 조금 다른 형태가 만들어지고, 정리본은 감수분열 과정에서 유사 서열 사이의 변화가 MHC 다양성에 기여했다고 설명합니다.


![gene conversion(왼쪽)과 class I, class II의 변이 위치(오른쪽) (슬라이드)](../../inputs/tcell_figs/f_gene_var.png)


class I에서는 alpha-1, alpha-2 영역이, class II에서는 beta-1 영역이 peptide 결합과 관련된 다양성을 보입니다.


결합 홈의 구조가 달라지면 결합하는 peptide의 종류도 달라집니다. 그래서 MHC polymorphism은 이름의 다양성이 아니라 어떤 항원을 T세포에 보여 줄 수 있는가와 직결되는 기능적인 다양성입니다.


이 연결, 즉 다양성이 곧 기능적 다양성이라는 점이 오늘의 핵심이라고 강조하셨습니다.



<a name="topic-11"></a>

### 5. peptide는 어떻게 MHC에 결합하나?


![MHC에 결합하는 peptide의 서열 비교 (슬라이드)](../../inputs/tcell_figs/f_anchor.png)

- 여러 peptide가 하나의 MHC에 결합한다고 해서 전체 아미노산 서열이 같아야 하는 것은 아닙니다. 특정 위치에 비슷한 성질의 아미노산이 반복해서 나오고, 정리본은 2번, 5번, 8번 위치를 예로 듭니다.
- 표를 볼 때는 전체 서열보다 공통된 위치와 성질을 먼저 찾아봅니다. 외워야 할 것은 번호가 아니라 결합의 원리입니다.


<a name="topic-12"></a>

### 6. MHC 종류는 왜 무한정 늘어나지 않나?

**핵심 답**

- 감염 방어 범위와 흉선에서의 T세포 선택 부담이 균형을 이룹니다.


사람 집단에서 MHC가 다양하면 모든 사람이 같은 감염원 회피 전략에 취약해질 가능성이 줄어듭니다. 자료는 EBV의 면역 회피, 특정 인구집단의 HLA 분포, 서아프리카에서 HLA-B53과 중증 말라리아의 관련성을 사례로 듭니다.


사례의 수치보다 중요한 메시지는 병원체와 숙주의 유전적 다양성이 서로 영향을 주고받는다는 것입니다.


그렇다면 MHC 종류가 많을수록 좋을 텐데 왜 무한정 늘어나지 않을까요? 다양한 MHC는 더 많은 peptide를 제시할 수 있지만 흉선(thymus)에서 T세포가 선택되는 조건도 더 복잡해지기 때문입니다. 자가 반응성과 적절한 면역 반응 사이의 균형이 필요합니다.

## 3장. MHC restriction과 예외적 T세포 반응

<a name="topic-13"></a>

### 1. T세포는 peptide와 MHC를 어떻게 함께 인식하나?

**핵심 답**

- peptide와 자기 MHC가 함께 맞아야 인식합니다.


T세포는 외래 peptide만 인식하지 않습니다. TCR이 맞는 peptide를 인식해야 하고, 그 peptide를 제시하는 MHC도 자신이 인식하도록 교육받은 종류여야 반응합니다. 이 두 조건을 같이 생각해야 합니다.


![MHC restriction: 세 가지 조합 (슬라이드)](../../inputs/tcell_figs/f_restriction.png)


왼쪽은 자기 MHC에 맞는 peptide가 올라가 인식되고, 가운데는 peptide가 같아도 MHC가 달라 인식되지 않으며, 오른쪽은 자기 MHC여도 TCR이 인식하지 못하는 peptide라 반응하지 않습니다.


따라서 T세포 인식의 대상은 분리된 peptide 하나가 아니라 peptide-MHC 복합체입니다.



<a name="topic-14"></a>

### 2. MHC restriction은 어떻게 밝혀졌나?

- 지금은 기본 지식처럼 들리지만 처음 밝혀졌을 때는 중요한 발견이었고, Doherty와 Zinkernagel의 연구가 대표적입니다. 특정 항원에 반응하는 T세포는 어떤 세포에서나 반응하는 것이 아니라 적절한 자기 MHC 환경에서 항원이 제시되어야 반응합니다.
- 실험의 세부사항을 따라가기보다, 항원은 같고 MHC가 다른 경우, MHC는 같고 항원이 다른 경우, 두 조건이 모두 맞는 경우로 나눠 무엇이 T세포 반응을 결정하는지 비교하는 사고방식을 익힙니다. 앞의 그림이 그 세 조합입니다.


<a name="topic-15"></a>

### 3. MHC restriction의 예외에는 무엇이 있나?

**핵심 답**

- alloresponse, 이식(transplantation), superantigen입니다.


자기 MHC에 제한되어 반응한다면 왜 장기 이식 때는 타인의 MHC에 엄청난 반응이 나타날까요? 이 예외처럼 보이는 현상이 이식 반응과 superantigen입니다.

- **개념 Check** MHC restriction이 적용되는 것은 alloresponse이다. (O, X) → X — alloresponse, transplantation, superantigen은 MHC restriction의 예외이다.


<a name="topic-16"></a>

### 4. 이식에서는 왜 타인의 MHC에 강하게 반응하나?

**핵심 답**

- TCR의 교차 반응성 때문에 alloreactive T세포가 약 1~10%나 됩니다.


alloresponse는 다른 개체의 MHC에 대해 일어나는 강한 T세포 반응입니다. 같은 종 사이의 이식은 allogeneic, 서로 다른 종 사이의 이식은 xenogeneic(xenograft)이라고 합니다.


T세포 수용체는 어느 정도 교차 반응성(cross-reactivity)이 있어서, 자기 MHC와 구조가 비슷한 다른 MHC에 예기치 않게 강하게 결합할 수 있습니다. 정리본은 alloreactive T cell이 전체 T세포의 약 1~10%라고 소개합니다.


![TCR의 CDR 부위와 MHC-peptide 복합체의 상호작용, alloresponse (슬라이드)](../../inputs/tcell_figs/f_alloresponse.png)


흉선(thymus)의 positive selection과 negative selection은 자기 MHC에 적절히 반응하는 세포를 남기지만, 타인의 MHC에 대한 반응까지 모두 없애 주지는 않습니다. 이식 거부반응을 이해할 때 이 점이 중요합니다.


이 반응을 보는 고전적인 실험이 mixed lymphocyte reaction(MLR)입니다. MHC가 다른 두 개체의 림프구를 섞어 반응을 보는데, 양쪽이 모두 증식하면 구별하기 어렵기 때문에 한쪽은 irradiation이나 mitomycin C로 증식하지 못하게 해서 처리하지 않은 쪽의 반응을 봅니다.

- **개념 Check** 유전적으로 동일하지 않은 같은 종의 개체 사이의 이식은 allogeneic transplantation이다. (O, X) → O — 다른 종 사이의 이식은 xenogeneic이다.


<a name="topic-17"></a>

### 5. superantigen은 일반 항원과 무엇이 다른가?

**핵심 답**

- peptide 처리 없이 MHC class II와 TCR을 연결해 많은 T세포를 활성화합니다.


정상적인 항원 제시는 peptide가 만들어져 MHC의 결합 홈에 자리하고, 특정 TCR이 그 복합체를 인식하는 과정입니다. superantigen은 일반적인 peptide 처리와 결합 방식과 다르게 MHC class II와 TCR을 연결해 많은 T세포를 동시에 활성화합니다.


![bacterial superantigen과 viral superantigen (슬라이드)](../../inputs/tcell_figs/f_superantigen.png)


많은 T세포가 한꺼번에 자극되면 염증성 신호가 크게 발생해 숙주에 심한 부담이 됩니다. 핵심은 ‘비특이적인 대규모 활성화’이고, 그림에서도 결합 위치가 일반적인 peptide-MHC-TCR 인식과 다른 점을 먼저 봅니다.



<a name="chapter-4"></a>

## 4장. Class Ib 분자와 비전형적 T세포

<a name="topic-18"></a>

### 1. 비전형적 MHC(class Ib)에는 무엇이 있나?

**핵심 답**

- HLA-E, F, G가 중심이고 NK세포와 모체-태아 면역에 관여합니다.


지금까지는 고전적 MHC와 peptide 항원을 다뤘고, 이 틀로 설명하기 어려운 인식 방식과 연결된 분자를 class Ib, nonclassical MHC 또는 MHC-like molecule이라고 부릅니다. 분류 용어는 자료마다 조금 다르므로 기능을 함께 봅니다.


class Ib는 고전적 class I과 형태가 비슷하지만 다형성이 제한적인 경우가 많고 기능이 다양합니다. 자료는 HLA-E, F, G를 중심으로 보라고 강조합니다.

- **개념 Check** HLA-C는 NK세포의 KIR과 결합해 NK세포를 억제한다. (O, X) → O — HLA-C는 class I이면서 NK세포 수용체와 상호작용한다.


<a name="topic-19"></a>

### 2. Unconventional T cell은 무엇을 인식하나?

**핵심 답**

- peptide-MHC 밖의 항원을 인식하는 gamma-delta T, MAIT, iNKT입니다.


unconventional T cell로 정리본은 gamma-delta T cell, 점막과 관련된 MAIT cell, invariant NKT cell을 듭니다. 인식하는 표적과 생리적 역할은 서로 같지 않습니다.


먼저 고전적인 alpha-beta T세포의 peptide-MHC 인식과 다른 항원 인식 경로가 있다는 것을 잡습니다.


![gamma-delta T cell을 활성화하는 ligand (슬라이드)](../../inputs/tcell_figs/f_gdT.png)


표에는 gamma-delta T cell이 인식하는 ligand가 여러 가지로 제시되어 있습니다. 항목을 모두 암기하기보다 고전적인 peptide-MHC 인식과 다른 방식으로 다양한 신호를 감지한다는 점이 중요합니다.


MAIT cell은 점막 면역과 관계가 있고 미생물 유래 물질을 인식하며, 선천면역과 적응면역 사이를 연결하는 성격으로 설명됩니다.



<a name="topic-20"></a>

### 3. CD1과 FcRn은 무엇을 제시하나?

- CD1은 국가시험에 자주 나온다고 강조하셨다고 정리본에 적혀 있으니 ‘CD1—지질 항원제시’를 확실히 기억합니다.
- 정리본은 CD1c와 invariant NKT cell을 연결하지만, 일반적으로 invariant NKT cell의 대표 인식 분자는 CD1d입니다. 이 연결은 복습할 때 검증이 필요합니다.

![CD1c(왼쪽)와 CD1d(오른쪽)에 지질이 결합한 모습 (슬라이드)](../../inputs/tcell_figs/f_cd1.png)

- **개념 Check** CD1c는 invariant NKT cell을 활성화한다. (O, X) → O — CD1은 lipid 항원을 제시한다.
