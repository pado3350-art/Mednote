# T림프구 항원제시: MHC 유전자와 T세포 인식 — 기출(PAD) 해설

기출 18문항을 6개 유형으로 묶었습니다. 문제·정답·PAD 해설은 PAD 파일 그대로이고(파랑 = PAD 내용), ‘이번 강의 기준 해설’은 이번 스크립트로 쓴 노트의 근거 문장과 직접 쓴 해설이며 유형마다 한 번만 씁니다.

## 유형 1. 다형성이 가장 큰 유전자좌 (4문항: 2022년(20학번) Q1, 2020년(18학번) Q1, 2019년(18학번) Q1, 2018년(17학번) Q3)

### 기출 2022년 20학번 김태규 교수님 Q1

- 문제: 다음 중 사람의 MHC class I에 해당하는 HLA 유전자 중 가장 다형성(polymorphism) 이 높은 유전자좌(locus) 명은? ① HLA-A ② HLA-B ③ HLA-C ④ HLA-E ⑤ HLA-F
- 정답: 2번
- PAD 해설: 올해는 설명 안 하셨지만, 일단 파드에 있길래 애플에도 설명을 추가했다. Class I의 polymorphism은 B>A>C 순이다. 참고로 class II는 DRB>DQB>DPB이다. 올해 설명하신 내용은, Class I이 Class II보다 polymorphism이 크다는 것.
- 이번 강의로 보면: 정답 ② HLA-B: class I 중 다형성이 가장 높은 유전자좌입니다(B > A > C).

### 기출 2020년 18학번 김태규 교수님 Q1

- 문제: HLA class 1 중 대립유전자(allele)의 다양성이 가장 많은 것은? 1) HLA A 2) HLA B 3) HLA C 4) HLA DR 5) HLA DP
- 정답: 2번
- PAD 해설: 짤인 문제였네요. 올해는 자세히 설명하신 부분은 아니지만, 강의자료 그림을 통해 분명히 알 수 있는 부분이기 때문에 알아는 둡시다.
- 이번 강의로 보면: 정답 ② HLA B: 20학번 문제와 같은 유형이고 ‘짤’이었습니다.

### 기출 2019년 18학번 김태규 교수님 Q1

- 문제: MHC Class2에 속하면서 가장 polymorphic한 것은? 1) HLA-A 2) HLA-B 3) HLA DB 4) HLA DQ 5) HLA DR
- 정답: 5번
- PAD 해설: MHC class II라고 했기 때문에 1번과 2번은 제껴줍니다. MHC class II의 polymorphic한 순서는 (D) P<Q<R이었습니다. 정답은 5번.
- 이번 강의로 보면: 정답 ⑤ HLA-DR: class II 중 DR > DQ > DP이고, HLA-A, B는 class I이라 제외합니다.

### 기출 2018년 17학번 김태규 교수님 Q3

- 문제: HLA type II 중에서 유전적 다양성이 가장 큰 것은? 1) HLA-DRA 2) HLA-DRB 3) HLA-DQA 4) HLA-DQB 5) HLA-DPA
- 정답: 2번
- PAD 해설: 김태규 교수님 이거 진짜 좋아하시네요… 이번 시간 강의에서 중요하게 봐야 할 부분은 A에 비해서 B가 다양성이 훨씬 크다는 것입니다!
- 이번 강의로 보면: 정답 ② HLA-DRB: A chain보다 B chain의 다양성이 훨씬 큽니다.

**이번 강의 기준 해설**

고전적 class I에서는 HLA-B > HLA-A > HLA-C 순으로, class II에서는 DRB > DQB > DPB 순으로 다형성이 큽니다. class II의 다형성은 beta chain 쪽에 집중되어 있고, class Ib는 상대적으로 제한적입니다. 다형성은 peptide가 들어가는 결합 부위와 관련됩니다. 이번 수업은 최신 allele 개수를 외우기보다 상대적인 경향과 기능을 이해하라고 했습니다.

- [polygeny와 polymorphism의 구분, 다형성의 순서] 표: class I · HLA-A, HLA-B, HLA-C · HLA-B > HLA-A > HLA-C / class II · HLA-DR, HLA-DP, HLA-DQ · DRB > DQB > DPB, beta chain 쪽에 다형성 집중 / class Ib · HLA-E, HLA-F, HLA-G 등 · 상대적으로 제한적
- [Take home messages] 2. 다형성 순서: class I B > A > C, class II DRB > DQB > DPB★

## 유형 2. CD1c와 invariant NKT cell (1문항: 2021년(19학번) Q1)

### 기출 2021년 19학번 김태규 교수님 Q1

- 문제: CD1c가 활성화 시키는 것은? 1) NK cell 2) NKT cell 3) B cell 4) α:β T cell 5) δ:γ T cell
- 정답: 2번
- PAD 해설: CD1c는 invariant NKT cell을 활성화시킨다고 이번 수업 시간에도 언급되었다. 참고로 CD1c가 제시하는 것은 lipid이다. 올해 꽤나 강조하신 부분이니 눈에 한번 더 담아두자.
- 이번 강의로 보면: 정답 ② NKT cell: PAD 해설은 CD1c가 invariant NKT cell을 활성화한다고 설명하며, CD1c가 제시하는 것은 lipid입니다.

**이번 강의 기준 해설**

CD1은 peptide가 아니라 lipid 또는 glycolipid 항원을 제시합니다. 정리본은 CD1c와 invariant NKT cell을 연결하지만, 일반적으로 invariant NKT cell의 대표 인식 분자는 CD1d이므로 이 연결은 복습할 때 검증이 필요합니다.

- [비전형적 T세포와 CD1] CD1은 peptide가 아니라 lipid 또는 glycolipid 항원을 제시합니다. 그래서 병원체에서 온 지질 항원을 인식하는 경로와 연결됩니다. CD1a부터 CD1e까지 여러 유형이 있습니다. CD1c는 invariant NKT cell을 활성화합니다.
- [Take home messages] 5. HLA-C는 KIR로 NK세포 억제, CD1c는 lipid 항원으로 iNKT 활성화★

## 유형 3. MHC class 구분 (class I, class II, class Ib) (4문항: 2021년(19학번) Q2, 2018년(17학번) Q2, 2016년(14학번) Q1, 2010년(08학번) Q1)

### 기출 2021년 19학번 김태규 교수님 Q2

- 문제: MHC class 2에 해당하는 것은? 1) HLA-A 2) HLA-B 3) HLA-C 4) HLA-DR 5) HLA-E
- 정답: 4번
- PAD 해설: 1글자 짜리는 MHC class I, 2글자 짜리는 MHC class II region에서 나온다고 외워두자. 올해 역시 HLA를 위주로 보라는 말씀이 있었으니 출제 유력 주제 중 하나라고 볼 수 있지 않을까?
- 이번 강의로 보면: 정답 ④ HLA-DR(class II). HLA-A, B, C는 class I이고 HLA-E는 class Ib입니다.

### 기출 2018년 17학번 김태규 교수님 Q2

- 문제: 다음 중 CD8에 바이러스 항원을 제공할 수 있는 물질은? 1) HLA-B 2) HLA-E 3) HLA-F 4) HLA-DM 5) HLA-DO
- 정답: 1번
- PAD 해설: 한번 생각을 하게 만드는 문제네요. CD8에 제공하려면 MHC class I이어야겠죠? MHC class I은 HLA-A, B, C입니다. E,F,G는 class I region에 존재하지만 class I의 역할을 한다고 보긴 어려워요.
- 이번 강의로 보면: 정답 ① HLA-B: 고전적 class I(HLA-A, B, C)입니다. HLA-E, F는 class I 영역에 있어도 고전적 class I의 역할을 한다고 보기 어렵고, HLA-DM, DO는 class II 영역에서 peptide editing과 조절에 관여합니다. ‘CD8에 항원을 제시한다’는 설명은 PAD 해설에서 가져온 것이고 스크립트에는 없습니다.

### 기출 2016년 14학번 김태규 교수님 Q1

- 문제: 다음 중 사람에서 MHC class 1b 분자에 해당하는 것은? 1. HLA-A 2. HLA-B 3. HLA-C 4. HLA-F 5. HLA-DR
- 정답: 3,4번
- PAD 해설: 답이 4번으로 복구되어있긴 한데, 오늘 수업 기준으로 3번과 4번 모두 정답인 것 같습니다. HLA-C는 MHC class I에 속하지만 MHC class 1b로 분류할 수도 있습니다.
- 이번 강의로 보면: 정답 3, 4번: PAD 해설은 답이 4번으로 복구되어 있지만 이번 수업 기준으로 HLA-C와 HLA-F 모두 해당한다고 봅니다. HLA-F는 class Ib이고, HLA-C는 class I이면서 class Ib로도 분류할 수 있습니다.

### 기출 2010년 08학번 김태규 교수님 Q1

- 문제: 다음 중 T cell에 항원을 제시하지 않는 것은? ① HLA-A ② HLA-B ③ HLA-C ④ HLA-DR ⑤ HLA-E
- 정답: 5번
- PAD 해설: HLA-E cell은 NK-cell을 억제하는 class 1b molecule이었습니다. HLA-C는 MHC class I로서의 역할도 하기 때문에 정답은 아닙니다.
- 이번 강의로 보면: 정답 ⑤ HLA-E: T세포에 항원을 제시하지 않고 NK세포를 억제하는 class Ib 분자입니다. HLA-C는 class I의 역할도 하므로 정답이 아닙니다.

**이번 강의 기준 해설**

MHC class I은 HLA-A, B, C(alpha chain 1개 + beta-2 microglobulin, ‘다리 하나짜리’), class II는 HLA-DR, DP, DQ(alpha chain과 beta chain이 짝, ‘다리 두 개짜리’)입니다. HLA-E, F, G는 class I 영역에 있지만 다형성이 제한적인 class Ib(비고전적)이고, 이 가운데 HLA-E는 NK세포에 억제 신호를 주는 경로와 연결됩니다. HLA-C는 class I이면서 NK세포 수용체와 상호작용해 class Ib로도 분류할 수 있습니다. 문제가 ‘class II 분자’를 묻는지 ‘class II region의 유전자’를 묻는지도 구분해서 읽습니다.

- [MHC 유전자 영역의 구성: class I, II, III] 표: 분자 · HLA-A, HLA-B, HLA-C · HLA-DR, HLA-DP, HLA-DQ / 구조 · alpha chain 1개 + beta-2 microglobulin, → ‘다리 하나짜리’(교수님 표현) · alpha chain과 beta chain이 짝, → ‘다리 두 개짜리’(교수님 표현) / T세포 · CD8 T세포에 항원 제시 · CD4 T세포에 항원 제시
- [MHC 유전자 영역의 구성: class I, II, III] 6번 염색체의 HLA 영역이고, class I, II, III로 나눕니다.
- [Take home messages] 3. class I은 HLA-A, B, C, class II는 HLA-DR, DP, DQ★
- [Class Ib 분자: HLA-E, F, G] 표: HLA-C · NK세포 수용체(KIR)와 상호작용 → NK세포 억제 · class I이면서 class Ib로도 분류 / HLA-E · NK세포 억제 신호 · T세포에 항원 제시 안 함 / HLA-F · class Ib의 중심 분자 중 하나 ·  / HLA-G · 모체와 태아 사이의 면역 조절 · 
- [Class Ib 분자: HLA-E, F, G] HLA-E, F, G가 중심이고 NK세포와 모체-태아 면역에 관여합니다.

## 유형 4. NK세포와 class Ib 분자 (5문항: 2019년(18학번) Q2, 2018년(17학번) Q1, 2016년(14학번) Q2, 2015년(13학번) Q1, 2015년(13학번) Q2)

### 기출 2019년 18학번 김태규 교수님 Q2

- 문제: .NK cell을 억제하기 위해 kir receptor 결합하는 HLA는? 1) HLA-A 2) HLA-B 3) HLA-C 4) MIC-A 5) MIC-B
- 정답: 3번
- PAD 해설: 이번 수업에서 KIR receptor는 언급되지 않았지만, HLA-C가 NK-cell을 억제한다는 것은 언급되었습니다. 사실 표에 KIRs라고 적혀있긴 한데… 설마 이런 걸 낼까요 ㅎㅎ
- 이번 강의로 보면: 정답 ③ HLA-C: KIR과 결합해 NK세포를 억제합니다. KIR이라는 이름은 스크립트에 없습니다.

### 기출 2018년 17학번 김태규 교수님 Q1

- 문제: 다음 중 MHC1b class에 속하는 molecule으로 MICA/B와 결합하는 물질은? 1) alpha-Galcer 2) microbial folate metabolites 3) MR1 4) N-formylated peptides 5) NKG2D
- 정답: 5번
- PAD 해설: NKG2D는커녕 MICA/B도 별로 중요하게 설명하지 않으셨습니다. 물론 강의자료에 있는 표에는 있긴 합니다만…
- 이번 강의로 보면: 정답 ⑤ NKG2D: MICA/B와 결합하는 수용체입니다. 스크립트는 MIC-A, MIC-B가 class III 영역에 있다는 점만 다뤘습니다.

### 기출 2016년 14학번 김태규 교수님 Q2

- 문제: 다음 중 NK 세포를 활성화하는 NKG2D 수용체와 결합하는 것은? 1. MHC class 1 2. MHC class 2 3. MICA 4. NKp30 5. NKp46
- 정답: 3번
- PAD 해설: 표에는 나와있지만 언급하시지 않으셨습니다. MICA가 NK-cell의 활성과 관련이 있다는 것 정도 알아둡시다.
- 이번 강의로 보면: 정답 ③ MICA: NKG2D 수용체와 결합해 NK세포를 활성화합니다. 스크립트에서는 다루지 않았고 PAD 해설도 표에만 있다고 합니다.

### 기출 2015년 13학번 김태규 교수님 Q1

- 문제: 다음 중 NK cell 의 inhibitory receptor (KIR)에 결합하는 것은? 1) MIC-A or MIC-B 2) RAET1 family (ULBPs) 3) NKG2D 4) MHC class I 5) MHC class II
- 정답: 4번
- PAD 해설: NK cell의 KIRs에 붙는 것은 HLA-C라고 표에 나와있었죠. HLA-C는 MHC class I에 속한다고 볼 수 있습니다.
- 이번 강의로 보면: 정답 ④ MHC class I(HLA-C): NK세포의 억제 수용체(KIR)에 결합합니다.

### 기출 2015년 13학번 김태규 교수님 Q2

- 문제: 사람에서 MHC class 1b 분자에 해당되며 NKG2A 와 NKG2C 수용체와 결합하여 NK 세포를 억제하는 것은? 1. HLA-C 2. HLA-E 3. HLA-F 4. HLA-G 5. HLA-DM
- 정답: 2번
- PAD 해설: 표에 나와있긴 한데… 자세히 배우지는 않았습니다.
- 이번 강의로 보면: 정답 ② HLA-E: NKG2A, NKG2C와 결합해 NK세포를 억제하는 class Ib입니다. 수용체 이름은 스크립트에 없고 표에만 있습니다.

**이번 강의 기준 해설**

이번 스크립트에서 NK세포와 관련해 다룬 것은 세 가지입니다. 일부 class Ib 분자(HLA-E, F, G)가 NK세포에 억제 신호를 주는 경로와 연결되고, HLA-G는 모체와 태아 사이의 면역 조절과 관련되며, HLA-C도 NK세포 수용체와 상호작용합니다. MIC-A, MIC-B는 class III 영역에 있는 분자로만 언급했고, KIR과 NKG2D 같은 수용체 이름은 직접 다루지 않았습니다(PAD 해설도 표에는 있지만 강조하지 않았다고 설명합니다).

- [Class Ib 분자: HLA-E, F, G] 표: HLA-C · NK세포 수용체(KIR)와 상호작용 → NK세포 억제 · class I이면서 class Ib로도 분류 / HLA-E · NK세포 억제 신호 · T세포에 항원 제시 안 함 / HLA-F · class Ib의 중심 분자 중 하나 ·  / HLA-G · 모체와 태아 사이의 면역 조절 · 
- [Class Ib 분자: HLA-E, F, G] HLA-E, F, G가 중심이고 NK세포와 모체-태아 면역에 관여합니다.
- [Take home messages] 5. HLA-C는 KIR로 NK세포 억제, CD1c는 lipid 항원으로 iNKT 활성화★
- [MHC 유전자 영역의 구성: class I, II, III] class III 영역에는 MIC-A, MIC-B가 있습니다. 면역 관련 유전자가 이렇게 한 영역에 모여 있어서, 뒤에서 나올 면역 반응의 공동 조절이 자연스럽게 이해됩니다.

## 유형 5. MHC restriction의 예외와 이식 (3문항: 2018년(16학번) Q1, 2016년(14학번) Q3, 2011년(09학번) Q1)

### 기출 2018년 16학번 이성범 교수님 Q1

- 문제: 아래에 설명된 장기이식의 종류는 무엇인가? - 유전적으로 동일하지 않는 사람들 간의 장기이식이다. - 이식 후 반드시 면역억제제의 치료가 필요한 장기이식이다. - 일반적으로 가장 많이 시행되고 있는 장기이식이다. 1) allogenic transplatation 2) autologus transplatation 3) isogenic transplantation 4) syngeneic transplatation 5) xenotrasplatation
- 정답: 1번
- PAD 해설: Allogenic transplatation. 같은 종 다른 개체에게 받는 것이라고 배웠었죠. Xenotransplatation은 다른 종에서 받는 것이라고도 배웠습니다. 나머지는 몰라요.
- 이번 강의로 보면: 정답 ① allogeneic transplantation: 유전적으로 동일하지 않은 같은 종의 개체 사이의 이식입니다. xenotransplantation은 다른 종 사이의 이식입니다.

### 기출 2016년 14학번 김태규 교수님 Q3

- 문제: 다음중 MHC restriction 이 적용되는것은?? 1) adoptive T cell therapy 2) alloresponse 3) transplantation 4) superantigens 5) NK cell
- 정답: 1번
- PAD 해설: 2~4번이 MHC restriction의 예외라는 것이 수업에 언급되었습니다. NK-cell은 비특이적 면역 반응이기 때문에 MHC restriction과는 거리가 멀지 않을까요?
- 이번 강의로 보면: 정답 ① adoptive T cell therapy: 나머지(alloresponse, transplantation, superantigen)가 MHC restriction의 예외입니다. NK세포는 비특이적 반응이라 거리가 멉니다(PAD 해설). adoptive T cell therapy 자체는 스크립트에서 다루지 않았습니다.

### 기출 2011년 09학번 김태규 교수님 Q1

- 문제: 다음중 MHC restriction 이 적용되는것은?? 1) transplantation 2) alloresponse 3) adoptive T cell therapy 4) superantigens 5) NK cell
- 정답: 3번
- PAD 해설: 선지 순서만 바꾼 짤 문제입니다.
- 이번 강의로 보면: 정답 ③ adoptive T cell therapy: 선지 순서만 바꾼 같은 문제입니다.

**이번 강의 기준 해설**

T세포는 peptide와 자기 MHC를 함께 인식하고(MHC restriction), 이 틀의 예외로 이번 수업은 alloresponse, 이식(transplantation), superantigen을 들었습니다. 같은 종 사이의 이식은 allogeneic, 서로 다른 종 사이의 이식은 xenogeneic입니다.

- [MHC restriction의 예외: 이식 반응] TCR의 교차 반응성 때문에 alloreactive T세포가 약 1~10%나 됩니다.
- [Take home messages] 4. 일반 T세포 반응 = peptide + 자기 MHC, 예외는 alloresponse, 이식, superantigen★
