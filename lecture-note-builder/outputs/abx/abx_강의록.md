# Clinical Therapeutics: 중환자와 항균제

**작성자 코멘트**

- 임상약리 ‘Clinical Therapeutics: 중환자와 항균제’(한성필 교수님). 녹화 문답 영상(조성연, 한성필 교수님)을 틀고 교수님이 덧붙인 수업입니다. 그림은 정리본 PDF에서 이미지만 가져왔고 글은 스크립트로만 썼습니다.
- 노트는 4장입니다. ① 항균제 선택 원칙 ② 경험적 → 표적 치료 ③ 용량, 용법, 투여 경로 ④ PK/PD, 경로 원칙, 병용. 영상의 질문1은 ①, 질문2는 ③·④입니다. 파랑 글씨 = 기출(PAD)에 나온 내용입니다.
- 학습목표의 ‘미충족 의료 수요’는 이번 시간에 다루지 않았습니다.

**먼저 볼 내용**

- 기출 6문항(18~20학번)은 두 유형뿐입니다: ① 획득 경로 × 면역 4사분면 ② 시간 vs 농도 의존성 살균과 PAE. 앞쪽 두 표를 먼저 보세요.
- 교수님이 ‘시험 문제가 나왔다’고 한 4사분면(1장 §4)과 ‘중요하다’고 한 PK/PD(4장 §1)가 핵심입니다. 소리가 작았던 초반 영상은 가볍게 보셔도 됩니다.

**학습목표**

- 항균제의 목적에 따른 치료 전략을 설명할 수 있다.
- 항균제 용량과 용법의 결정 인자를 설명할 수 있다.
- 환자 개인차와 관련한 처방의의 고려점을 설명할 수 있다.
- 현재 항균제의 미충족 의료 수요를 설명할 수 있다(이번 시간에는 다루지 않음).

| 획득 경로 | 면역 상태 | 사례와 의미 |
|---|---|---|
| **[기출]** community acquired | **[기출]** competent | **[기출]** 건강했던 18세 남학생 (응급실)<br>**[기출]** 두통, 구토, 고열, 경부강직<br>**[기출]** → 병원 밖에서 감염, 면역 정상 |
| **[기출]** nosocomial | **[기출]** competent | **[기출]** 18세, 외상성 경막하 출혈로 개두술<br>**[기출]** 7일째 두통, 고열, 경부강직<br>**[기출]** → 침습적 수술 뒤 병원 감염, 젊어서 면역 결함 없음 |
| nosocomial | compromised | AML, BMT D12, 백혈구 200/mm³, 39 °C<br>두통, 구토, 경부강직<br>→ 면역저하 환자의 병원 감염 (슬라이드 사례) |

|---|---|---|
| 유리한 것 | **[기출]** MIC 이상 유지 시간이 길수록 | **[기출]** 잠깐이라도 고농도로 노출될수록 |
| 용법 | 저용량, 짧은 간격 | **[기출]** 고용량, 긴 간격 (투약 간격도 고려) |
| 대표 약물 | β-lactam<br>그림: vancomycin, macrolide, clindamycin | **[기출]** aminoglycoside<br>그림: fluoroquinolone |
| 지표 | T>MIC | Cmax/MIC, AUC/MIC |
| PAE | **[기출]** PAE(post-antibiotic effect): MIC 이하로 떨어진 뒤에도 항균 효과가 지속되는 것<br>그림: 작거나 중간 | 그림: PAE가 김 |
> **질문1** 항균제의 종류가 많은데, 감염 질환에 따라 항균제가 선택되는 원칙을 알고 싶습니다.
- A. 스펙트럼(어떤 균을 커버하는가)만 외워서는 부족하고, 사용 목적, 감염 장기, 환자 세 가지를 먼저 고려한다.
> **역질문1** 항균제를 쓰는 목적이 무엇인가?
- A. 목적은 감염, 증상, 원인균이 얼마나 확인되었는지로 네 가지로 나눈다.
| 구분 | 예방적 | 선제적 | 경험적 | 표적 |
|---|---|---|---|---|
| 영어 | prophylactic | pre-emptive | empiric | targeted |
| 감염 | 없음 | — | 모름 | 확인 |
| 증상 | 없음 | 아직 없음 | 있음 (예: 열) | 있음 |
| 원인균 | — | — | 아직 모름 | 확인됨 |
| 특징 | 수술 전 예방 | — | **가장 많이 사용** | 균 겨냥, 약 변경 |
> **역질문2** 어느 장기의 감염이 의심되는가?
- A. 증상으로 어느 장기인지 추론하면 그 장기에 흔한 균을 떠올릴 수 있고, 약이 그 장기에 닿는지도 따질 수 있다. 예: 두통과 발열이면 CNS 감염(뇌수막염)을 의심하고 BBB를 잘 통과하는 약을 고른다.
> **역질문3** 어떤 환자에게, 어떤 환경에서 사용하는가?
- A. 같은 감염, 같은 증상이라도 환자를 만나는 맥락에 따라 치료 전략이 달라진다. 획득 경로 × 면역 상태의 4사분면으로 나눈다.
| 획득 경로 | 면역 상태 | 사례와 의미 |
|---|---|---|
| **[기출]** community acquired | **[기출]** competent | **[기출]** 건강했던 18세 남학생 (응급실)<br>**[기출]** 두통, 구토, 고열, 경부강직<br>**[기출]** → 병원 밖에서 감염, 면역 정상 |
| **[기출]** nosocomial | **[기출]** competent | **[기출]** 18세, 외상성 경막하 출혈로 개두술<br>**[기출]** 7일째 두통, 고열, 경부강직<br>**[기출]** → 침습적 수술 뒤 병원 감염, 젊어서 면역 결함 없음 |
| nosocomial | compromised | AML, BMT D12, 백혈구 200/mm³, 39 °C<br>두통, 구토, 경부강직<br>→ 면역저하 환자의 병원 감염 (슬라이드 사례) |
| 획득 경로 | 환자 | 항균제 선택 |
|---|---|---|
| community acquired | 건강하던 사람 | ceftriaxone + vancomycin<br>50세 이상: Listeria 커버용 ampicillin 추가 |
| hospital-acquired | 뇌종양 수술 뒤 중환자실 | Pseudomonas(녹농균)를 고려<br>ceftriaxone 대신 ceftazidime 또는 meropenem + vancomycin |
| 구분 | 정균제 (bacteriostatic) | 살균제 (bactericidal) |
|---|---|---|
| 작용 | 세균의 증식을 억제 | 세균을 사멸 |
| 치유는 누가 | 최종 치료는 숙주 면역계에 의존 | 면역저하 환자, 중증 감염에서<br>주로 선택 |
|   |   |
|---|---|
| 면역 상태 | 중증 당뇨, 악성 종양, 면역억제제 → 감염이 무거워짐 → 고용량이나 장기간 투여<br>대가: 항균제 자체의 독성이 커지므로 용법 설정에 주의<br>면역억제 환자는 정균제 사용이 어렵고 살균제를 사용 |
| 신기능, 간기능 저하 | 그 장기로 제거되는 약의 혈중 농도 ↑ → 독성 위험 ↑<br>일부 약은 GFR, 간기능에 따른 용법 제한 기준이 있음<br>검사로 확인, 외래에서는 병력 청취가 중요 |
| 저관류 | 감염 부위의 혈류 ↓ → 약이 균에 충분히 닿지 못함 → 다른 방법을 고려 |
| 연령 | 신생아, 노인은 용법이 크게 달라짐<br>신생아는 대사 효소 기능이 미숙한 경우가 많음 |
> **질문2** 주사제도 있고 경구제도 있고, 항균제의 용량, 용법, 투여 경로는 어떻게 결정되나요?
- A. 대부분의 항균제는 용량과 용법이 이미 정해져 있고, 그 근거는 표적 균주의 MIC(Minimum Inhibitory Concentration) 프로파일, 반복 투여 때의 PK/PD 자료, 그리고 임상시험이다.
  그래도 고를 것이 남는다. 같은 3세대 cephalosporin도 하루 한 번 주는 약과 두 번 주는 약이 있다.
> **역질문1** 어떤 기관에 발생한 감염증인가?
- A. 약이 균이 있는 곳에 충분히 닿아야 하므로 기관마다 약과 경로를 바꾼다.
|   |   |
|---|---|
| CNS | BBB를 잘 통과하는 ceftriaxone, vancomycin을 CNS dose로<br>드문 감염(cryptococcal meningitis 등)은 척수강 내 투여(intrathecal therapy)로 CSF에 직접 주입하기도 함 |
| 안구 | IV 도달 불확실 → 유리체강 내 주사(intravitreal injection) |
| 뼈, 관절 | 혈관 분포 적음 → 약 도달 저하 가능 (bone and joint infection) |
| 호흡기 | 흡입 치료(inhalation therapy): 입자가 large airway까지만 가는지, alveoli(폐포)까지 가는지 고려<br>폐렴이면 alveoli까지 도달해야 함<br>일반 nebulizer와 aerosol generator 중 선택 |
| 분포 | tigecycline: 조직으로 잘 가지만 혈중 농도는 낮음<br>aminoglycoside: 혈중보다 요로(urinary tract)에서 훨씬 높음 |
> **역질문2** 어떤 환자에게 사용하는가?
- A. 같은 기관의 감염이라도 환자가 실제로 맞고 먹을 수 있어야 한다.
|   |   |
|---|---|
| 외래 vs 입원 | 외래: 경구가 기본, 하루 1회 주사실 IV도 있음<br>입원: 재원 기간 단축을 위해 조기 퇴원도 고려 |
| 혈관 상태 | 하루 3~4회 투여, sodium 많은 nafcillin → 정맥염(phlebitis) 잦음<br>nafcillin, vancomycin: 말초 정맥관 투여가 어려운 경우 많음 |
| 경구 섭취, 흡수 | 설사, GI bleeding → 경구약 효과 기대 어려움<br>동반 질환도 함께 확인 |
| 순응도 | 하루 3~4회 복용이 어려운 환자 → 하루 1회 약 유리<br>복용이 들쭉날쭉 → 치료 농도 저하 가능 |
| 생활 패턴 | 밤낮 바뀐 환자(예: 일부 HIV 감염인) → 하루 1회 약을 취침 전 복용으로 조정<br>식후 복용이 필수가 아닌 약에 한함 |
> **역질문3** 주사제가 경구제보다 효과가 우수한가?
- A. 입원 환자에게는 주사가 가장 약효가 빠르다는 고정관념이 있지만 항상 그렇지는 않고, 환자의 상태에 따라 접근이 달라진다.

|---|---|---|
| 유리한 것 | **[기출]** MIC 이상 유지 시간이 길수록 | **[기출]** 잠깐이라도 고농도로 노출될수록 |
| 용법 | 저용량, 짧은 간격 | **[기출]** 고용량, 긴 간격 (투약 간격도 고려) |
| 대표 약물 | β-lactam<br>그림: vancomycin, macrolide, clindamycin | **[기출]** aminoglycoside<br>그림: fluoroquinolone |
| 지표 | T>MIC | Cmax/MIC, AUC/MIC |
| PAE | **[기출]** PAE(post-antibiotic effect): MIC 이하로 떨어진 뒤에도 항균 효과가 지속되는 것<br>그림: 작거나 중간 | 그림: PAE가 김 |
| 지표 | 의미 | 해당 약물 (슬라이드) |
|---|---|---|
| T>MIC | MIC 위에 있는 시간의 비율<br>투여 간격 24시간 중 16시간이 MIC 위면 16/24 | β-lactam, vancomycin, macrolide, clindamycin |
| Cmax/MIC | 최고 농도를 MIC로 나눈 값<br>MIC가 약 5, Cmax가 약 15면 3 | aminoglycoside, fluoroquinolone |
| AUC/MIC | 곡선 아래 면적(area under the curve)을 MIC로 나눈 값<br>‘시간 의존성이 섞인 농도 의존성’으로 따로 나누기도 함 | vancomycin, azithromycin, fluoroquinolone, aminoglycoside, tigecycline, linezolid |
|   |   |
|---|---|
| 경구(PO)가 기본 | 가장 선호되는 경로, 특히 외래에서 자가 복용 가능<br>중증은 IV로 시작해도 가능하면 빨리 IV → PO switch |
| 주사가 필요할 때 | 경구로 충분한 혈장 농도를 못 얻을 때 (흡수 시간, bioavailability)<br>중증 감염, 패혈증처럼 긴급할 때<br>더 높은 혈장 농도가 필요할 때 |
|   |   |
|---|---|
| 병용이 유리한 경우 | 교대 감염<br>내성균 발현 억제<br>AIDS 치료(항균제는 아님), 특정 폐렴<br>항결핵제(당연히 병용)<br>요로 감염의 TMP/SMX(박트림) |
| 주의할 점 | 병용 약 사이의 PK, PD 상호작용<br>한 약이 다른 약의 대사에 영향 → 효과 감소, 부작용 증가 |
| 선택 기준 | ‘예전에 써 보니 좋더라’ 식의 병용은 지양 |

### 1. 항균제 선택은 무엇에서 시작하나?

- (수업은 녹화 문답 영상(감염내과 조성연 교수님, 한성필 교수님)을 틀고 교수님이 덧붙이는 방식이었습니다. 영상 재생 준비, 휴식과 출석 안내는 생략했습니다.)

## 2장. 경험적 → 표적 치료: 과정, 정균·살균, 환자 인자

<a name="topic-7"></a>

### 1. 경험적 치료에서 표적 치료로

**핵심 답**

- 감수성 검사로 균이 확인되면 표적 치료로 바꾼다.


경험적 치료는 원인균을 모르는 채 시작한다. 그럼 균이 확인된 뒤에는 어떻게 바꿀까?


![항균제 치료의 흐름](diagrams/diagram_02.png)


경험적 치료를 시작하는 동시에, 치료 전에 채취한 검체로 감수성 검사(susceptibility test)를 한다. 균과 항균제별 감수성(MIC, 최소 억제 농도)이 나오면 그 결과에 맞는 약으로 바꾼다(표적 치료, definitive therapy).


다만 경험적 치료가 이미 적절하면 그대로 두고, 바꿀지는 다음 다섯 가지로 판단한다.

- 감염 부위, 원인균, 감수성 패턴, 숙주(환자) 인자, 치료 반응(가장 중요)

지극히 상식적인 흐름이지만 실제로 지켜지지 않는 경우가 있어 기초부터 설명했다.



<a name="topic-8"></a>

### 2. 정균제와 살균제


![Bacteriostatic vs bactericidal agent: 약을 넣은 뒤 살아 있는 균 수 (슬라이드)](../../inputs/abx_figs/f2_static_cidal.png)

- 파란 선(정균제, 예: chloramphenicol)은 균 수가 유지되고, 빨간 선(살균제, 예: penicillin)은 살아 있는 균 수가 급격히 감소한다.
- 정균과 살균은 항균제의 농도나 균주에 따라 달라지는 상대적인 개념이다.

### 4. 주사(IV)는 항상 경구(PO)보다 나은가?


IV는 100% 들어가지만, 맞는 경로는 감염이 어디에 있느냐에 따라 다르다. 대표적인 예외가 장 안의 감염이다.


Clostridium difficile 감염(CDI)과 amebic colitis에는 흡수되지 않고 장관 안에 고농도로 머무는 luminal agent를 쓰고, 경구 vancomycin이 그런 약이다. 그래서 CDI에는 IV vancomycin이 아니라 경구 vancomycin이 맞다.


교수님 강조: 경구 vancomycin과 IV vancomycin의 차이를 이해하는 것이 중요하다.

### 4. QUIZ


**문제** 65세 남성이 뇌종양 수술 뒤 중환자실에 입원 중 세균성 뇌수막염이 의심된다. 가장 알맞은 경험적 항균제 조합은?

- ① ceftriaxone + vancomycin + ampicillin
- ② meropenem + vancomycin
- ③ 경구 vancomycin 단독
- ④ aminoglycoside 흡입 치료
- ⑤ 감수성 결과가 나올 때까지 항균제를 쓰지 않는다

<details>
<summary>정답과 해설</summary>

**정답:** ② meropenem + vancomycin

- ① 건강하던 사람의 community acquired 뇌수막염 조합이다
- ② 병원 감염이므로 Pseudomonas를 고려한다 (정답)
- ③ 경구 vancomycin은 흡수되지 않는 luminal agent다
- ④ 흡입 치료는 호흡기 감염의 선택지다
- ⑤ 경험적 치료는 감수성 검사와 동시에 시작한다

</details>


**문제** 투여 경로에 대한 설명으로 옳지 않은 것은?

- ① 외래에서는 경구 투여가 가장 선호된다
- ② 중증 환자도 가능하면 빨리 IV → PO로 바꾼다
- ③ 입원 환자에게는 주사가 항상 더 효과적이다
- ④ 경구로 적정 혈장 농도를 얻을 수 없으면 주사를 고려한다
- ⑤ 패혈증처럼 긴급한 경우에는 비경구 투여를 우선한다

<details>
<summary>정답과 해설</summary>

**정답:** ③ 입원 환자에게는 주사가 항상 더 효과적이다

- ① 스스로 먹을 수 있다
- ② 가능한 한 빨리 경구로 바꾸는 것이 유리하다
- ③ 주사가 늘 낫지는 않다. CDI에는 경구 vancomycin을 쓴다 (정답)
- ④ 흡수, bioavailability 문제 때문이다
- ⑤ 긴급한 항균 치료가 필요하다

</details>
