# Clinical Therapeutics: 중환자와 항균제

**작성자 코멘트**

- 임상약리 ‘Clinical Therapeutics: 중환자와 항균제’(한성필 교수님) 강의의 전체 스크립트를 정리했습니다. 수업은 몇 년 전 녹화한 문답 영상(감염내과 조성연 교수님, 한성필 교수님)을 틀고 교수님이 덧붙이는 방식이었습니다. 그림은 정리본 PDF에서 슬라이드 이미지만 가져왔고, 글은 스크립트로만 썼습니다.
- 노트는 강의 내용의 위계로 4장입니다. ① 항균제 선택 원칙(사용 목적, 감염 장기, 환자 맥락) ② 경험적 치료에서 표적 치료로(치료 과정, 정균제와 살균제, 환자 인자) ③ 용량, 용법, 투여 경로의 결정 ④ PK/PD, 투여 경로 원칙, 병용요법. 소절 순서는 스크립트가 흘러간 순서입니다(영상의 질문1은 ①, 질문2는 ③·④). 파랑 글씨 = 기출(PAD)에 나온 내용입니다([PAD …] 꼬리표가 출처).
- 학습목표의 ‘항균제 미충족 의료 수요’는 이번 시간에 다루지 않았습니다.

**먼저 볼 내용**

- 앞쪽 두 표가 기출 6문항(18~20학번)의 전부입니다: ① 획득 경로 × 면역 4사분면 ② 시간 의존성 vs 농도 의존성 살균과 PAE. 해마다 같은 유형이 반복됐습니다.
- 교수님이 ‘여기서 시험 문제가 나왔다’고 한 4사분면(1장 §4)과 ‘중요하다’고 한 PK/PD 지표(4장 §1)를 먼저 보세요.
- aminoglycoside = 농도 의존성(고용량, 긴 간격), β-lactam = 시간 의존성, PAE = MIC 아래에서도 효과 지속. 이 세 줄이 선지에 반복됩니다.
- 교수님은 ‘실제 중요한 것은 영상의 두 번째 질문(③·④장)에서 많이 나왔다’고 했습니다. 소리가 작았던 초반 영상은 가볍게 보셔도 됩니다.

**학습목표**

- 항균제의 목적에 따른 치료 전략을 설명할 수 있다.
- 항균제 용량과 용법의 결정 인자를 설명할 수 있다.
- 환자 개인차와 관련한 처방의의 고려점을 설명할 수 있다.
- 현재 항균제의 미충족 의료 수요를 설명할 수 있다(이번 시간에는 다루지 않음).

| 획득 경로 | 면역 상태 | 사례와 의미 |
|---|---|---|
| **[기출]** community acquired | **[기출]** competent | **[기출]** 건강했던 18세 남학생, 두통, 구토, 고열, 경부강직 (응급실)<br>**[기출]** → 병원 밖에서 감염, 면역 정상 |
| **[기출]** nosocomial | **[기출]** competent | **[기출]** 18세, 외상성 경막하 출혈로 개두술, 7일째 두통, 고열, 경부강직<br>**[기출]** → 침습적 수술 뒤 병원 감염, 젊어서 면역 결함 없음 |
| nosocomial | compromised | AML, BMT D12, 백혈구 200/mm³, 39 °C, 두통, 구토, 경부강직<br>→ 면역저하 환자의 병원 감염 (슬라이드 사례) |

|---|---|---|

| 용법 | 저용량, 짧은 간격 | **[기출]** 고용량, 긴 간격 (투약 간격도 고려) |

| 지표 | T>MIC | Cmax/MIC, AUC/MIC |
| PAE | **[기출]** MIC 이하로 떨어진 뒤에도 항균 효과가 지속되는 것<br>그림: 작거나 중간 | 그림: 길다 |
> **질문1** 항균제의 종류가 많은데, 감염 질환에 따라 항균제가 선택되는 원칙을 알고 싶습니다.
- A. 스펙트럼(어떤 균을 커버하는가)만 외워서는 부족하고, 사용 목적, 감염 장기, 환자 세 가지를 먼저 고려한다.
> **역질문1** 항균제를 쓰는 목적이 무엇인가?
- A. 목적은 감염, 증상, 원인균이 얼마나 확인되었는지로 네 가지로 나눈다.
|  | 예방적 (prophylactic) | 선제적 (pre-emptive) | 경험적 (empiric) | 표적 (targeted) |
|---|---|---|---|---|
| 감염 | 없음 | — | 모름 | 확인 |
| 증상 | 없음 | 아직 없음 | 있음 (예: 열) | 있음 |
| 원인균 | — | — | 아직 모름 | 확인됨 |
| 특징 | 수술 전 예방적 항균제 | — | **가장 많이 쓴다** | 균을 겨냥해 바꾼다 |
> **역질문2** 어느 장기의 감염이 의심되는가?
- A. 증상으로 어느 장기인지 추론하고, 그 장기에 흔한 균과 약이 닿는지를 함께 본다. 예: CNS 감염이면 BBB를 잘 통과하는 항균제.
> **역질문3** 어떤 환자에게, 어떤 환경에서 사용하는가?
- A. 같은 감염, 같은 증상이라도 환자를 어떤 맥락에서 만나느냐가 치료 전략을 정한다. 획득 경로와 면역 상태의 4사분면으로 나눈다.
| 획득 경로 | 면역 상태 | 사례와 의미 |
|---|---|---|
| **[기출]** community acquired | **[기출]** competent | **[기출]** 건강했던 18세 남학생, 두통, 구토, 고열, 경부강직 (응급실)<br>**[기출]** → 병원 밖에서 감염, 면역 정상 |
| **[기출]** nosocomial | **[기출]** competent | **[기출]** 18세, 외상성 경막하 출혈로 개두술, 7일째 두통, 고열, 경부강직<br>**[기출]** → 침습적 수술 뒤 병원 감염, 젊어서 면역 결함 없음 |
| nosocomial | compromised | AML, BMT D12, 백혈구 200/mm³, 39 °C, 두통, 구토, 경부강직<br>→ 면역저하 환자의 병원 감염 (슬라이드 사례) |
| 획득 경로 | 환자 | 항균제 선택 |
|---|---|---|
| community acquired | 건강하던 사람 | ceftriaxone + vancomycin<br>50세 이상이므로 Listeria를 커버하는 ampicillin 추가 |
| hospital-acquired | 뇌종양 수술 뒤 중환자실 | Pseudomonas(녹농균)를 고려<br>ceftriaxone 대신 ceftazidime 또는 meropenem + vancomycin |
|  | 정균제 | 살균제 |
|---|---|---|
| 작용 | 세균의 증식을 억제 | 세균을 사멸 |
| 치유는 누가 | 최종 치료는 숙주의 면역계에 기댄다 | 그래서 면역저하 환자(immunocompromised patient), 중증 감염에서 주로 선택 |
| 그림 (균 수) | 유지 (예: chloramphenicol) | 급감 (예: penicillin) |
|   |   |
|---|---|
| 면역 상태 | 중증 당뇨, 악성 종양, 면역억제제 → 감염이 무거워짐 → 고용량이나 장기간 투여<br>대가: 항균제 자체의 독성이 커지므로 용법을 주의해 정한다<br>면역억제 환자는 정균제가 어렵고 살균제를 쓴다 |
| 신기능, 간기능 저하 | 그 장기로 제거되는 약의 혈중 농도 ↑ → 독성 위험 ↑<br>일부 약은 GFR이나 간기능에 따른 용법 제한 기준이 있다<br>검사로도 확인하지만 외래에서는 병력 청취(history taking)가 중요하다 |
| 저관류 (hypoperfusion) | 감염 부위의 혈류 ↓ → 약이 균에 충분히 닿지 못함 → 다른 방법을 고려 |
| 연령 | 신생아와 노인은 용법이 크게 달라진다<br>신생아는 대사 효소 기능이 미숙한 경우가 많다 |
> **질문2** 주사제도 있고 경구제도 있고, 항균제의 용량, 용법, 투여 경로는 어떻게 결정되나요?
- A. 대부분의 항균제는 용량과 용법이 이미 정해져 있고, 그 근거는 표적 균주의 MIC 프로파일, 반복 투여 때의 PK/PD 자료, 그리고 임상시험이다.
  그래도 고를 것이 남는다. 같은 3세대 cephalosporin도 하루 한 번 주는 약과 두 번 주는 약이 있다.
> **역질문1** 어떤 기관에 발생한 감염증인가?
- A. 약이 균이 있는 곳에 충분히 닿아야 하므로 기관마다 약과 경로를 바꾼다.
|   |   |
|---|---|
| CNS | BBB를 잘 통과하는 ceftriaxone, vancomycin을 CNS dose로<br>드문 감염(cryptococcal meningitis 등)은 척수강 내 투여(intrathecal therapy)로 CSF에 바로 넣기도 한다 |
| 안구 | IV로는 도달이 의심스럽다 → 유리체강 내 주사(intravitreal injection) |
| 뼈, 관절 | 혈관 분포가 풍부한 기관보다 약이 덜 닿을 수 있다 (bone and joint infection) |
| 호흡기 | 흡입 치료(inhalation therapy): 입자가 large airway까지만 가는지, alveoli(폐포)까지 가는지가 문제다. 폐렴이면 alveoli까지 가야 한다<br>일반 nebulizer와 aerosol generator 중에서 고른다 |
| 분포 (distribution) | tigecycline: 조직으로 잘 가지만 혈중 농도는 낮다<br>aminoglycoside: 혈중보다 요로(urinary tract)에서 훨씬 높다 |
> **역질문2** 어떤 환자에게 사용하는가?
- A. 같은 기관의 감염이라도 환자가 실제로 맞고 먹을 수 있어야 한다.
|   |   |
|---|---|
| 외래 vs 입원 | 외래는 경구가 기본이다. 그래도 하루 한 번 주사실에서 IV를 맞는 경우가 있다<br>입원 환자도 재원 기간을 줄이려 일찍 퇴원시키기도 한다 |
| 혈관 상태 | 하루 3~4번 맞거나 sodium이 많은 nafcillin을 쓰면 정맥염(phlebitis)이 잘 생긴다<br>nafcillin, vancomycin은 말초 정맥관(peripheral line)으로 맞기 힘든 경우가 많다 |
| 경구 섭취, 흡수 | 설사가 계속되거나 GI bleeding이 있으면 경구약의 효과(efficacy)를 기대하기 어렵다<br>동반 질환도 함께 본다 |
| 순응도 (compliance) | 하루 3~4번 챙기기 힘든 바쁜 환자에게는 하루 1번 약이 낫다<br>먹다 안 먹다 하면 치료 농도(therapeutic level)가 떨어진다 |
| 생활 패턴 | 밤낮이 바뀐 환자(예: 일부 HIV 감염인)는 하루 1번 약을 자기 전에 먹게 한다<br>식후 복용이 꼭 필요한 약이 아닐 때 가능하다 |
> **역질문3** 주사제가 경구제보다 효과가 우수한가?
- A. 입원 환자에게는 주사가 가장 약효가 빠르다는 고정관념이 있지만 항상 그렇지는 않고, 환자의 상태에 따라 접근이 달라진다.

|---|---|---|
| 유리한 것 | **[기출]** MIC 이상 유지 시간이 길수록 | **[기출]** 잠깐이라도 고농도로 노출될수록 |
| 용법 | 저용량, 짧은 간격 | **[기출]** 고용량, 긴 간격 (투약 간격도 고려) |
| 대표 약물 | β-lactam<br>그림: vancomycin, macrolide, clindamycin | **[기출]** aminoglycoside<br>그림: fluoroquinolone |
| 지표 | T>MIC | Cmax/MIC, AUC/MIC |
| PAE | **[기출]** MIC 이하로 떨어진 뒤에도 항균 효과가 지속되는 것<br>그림: 작거나 중간 | 그림: 길다 |
| 지표 | 의미 | 해당 약물 (슬라이드) |
|---|---|---|
| T>MIC | MIC 위에 있는 시간의 비율<br>투여 간격 24시간 중 16시간이 MIC 위면 16/24 | β-lactam, vancomycin, macrolide, clindamycin |
| Cmax/MIC | 최고 농도를 MIC로 나눈 값<br>MIC가 약 5, Cmax가 약 15면 3 | aminoglycoside, fluoroquinolone |
| AUC/MIC | 곡선 아래 면적(area under the curve)을 MIC로 나눈 값<br>‘시간 의존성이 섞인 농도 의존성’으로 따로 나누기도 한다 | vancomycin, azithromycin, fluoroquinolone, aminoglycoside, tigecycline, linezolid |

| 주사(비경구)가 필요할 때 | 경구로 충분한 혈장 농도를 못 얻을 때 (흡수 시간, bioavailability)<br>중증 감염, 패혈증처럼 긴급할 때<br>더 높은 혈장 농도가 필요할 때 |

|---|---|
| 원칙 | 단일 제제 사용 |
| 병용이 유리한 경우 | 교대 감염<br>내성균 발현 억제<br>AIDS 치료(항균제는 아님), 특정 폐렴<br>항결핵제(당연히 병용)<br>요로 감염의 TMP/SMX(박트림) |
| 주의할 점 | 병용 약 사이의 PK, PD 상호작용<br>한 약이 다른 약의 대사에 영향 → 효과 감소, 부작용 증가 |
| 선택 기준 | 근거가 명확한 병용만 고른다<br>‘예전에 써 보니 좋더라’ 식의 병용은 피한다 |

## 1장. 항균제 선택 원칙: 사용 목적, 감염 장기, 환자 맥락

### 1. 항균제 선택은 사용 목적, 감염 장기, 환자 중 무엇에서 시작하나?

- (수업은 녹화 문답 영상(감염내과 조성연 교수님, 한성필 교수님)을 틀고 교수님이 덧붙이는 방식이었습니다. 영상 재생 준비, 휴식과 출석 안내는 생략했습니다.)

이 강의는 영상의 질문 두 개로 짜여 있다. 질문1은 항균제 선택 원칙이고, 질문2는 용량, 용법, 투여 경로의 결정이다. 학습목표도 목적에 따른 치료 전략, 용량과 용법의 결정 인자, 환자 개인차에 따른 고려점의 같은 순서다. 감염내과와 임상약리과는 항균제 PK/PD 분야에서 함께 연구를 많이 해 왔고, 미충족 의료 수요도 목표에 있었지만 이번 시간에는 다루지 않았다.


그래서 선택은 세 가지 질문을 차례로 던지는 일이다. 왜 쓰는가(목적), 어느 장기의 감염인가, 어떤 환자인가. 아래 세 소절이 이 순서로 하나씩 다룬다.

- **개념 Check** 항균제 선택의 첫 단계는 항균제의 스펙트럼을 외우는 것이다. (O, X) → X — 목적, 장기, 환자를 먼저 묻는다.


<a name="topic-3"></a>

### 2. 항균제 사용 목적 4가지(예방적, 선제적, 경험적, 표적 치료)는 어떻게 나누나?

- 즉 같은 항균제라도 감염, 증상, 원인균이 어디까지 확인되었는지에 따라 쓰는 목적이 달라진다. 선제적 치료는 소리가 작아 설명이 짧았다.
- **개념 Check** 원인균이 확인되기 전에 증상을 근거로 시작하는 치료는 경험적 치료이다. (O, X) → O


<a name="topic-4"></a>

### 3. 감염 장기(CNS 등)는 항균제 선택에 왜 중요한가?


장기를 알면 흔한 균을 떠올릴 수 있고, 약이 그 장기에 닿는지도 따질 수 있다. 두통과 발열이면 CNS 감염(뇌수막염)을 의심하고, 그러면 BBB(혈액뇌장벽)를 잘 통과하는 약을 고른다. 다만 같은 장기의 감염이라도 환자가 다르면 약이 달라지고, 그 기준이 다음 소절의 4사분면이다.

- **개념 Check** CNS 감염에서는 BBB를 잘 통과하는 항균제를 고른다. (O, X) → O


<a name="topic-5"></a>

### 4. 획득 경로(community acquired, nosocomial)와 면역 상태(competent, compromised)는 항균제 선택을 어떻게 바꾸나?


교수님은 이 4사분면 슬라이드가 굉장히 중요하고, 여기서 시험 문제가 나왔다고 했다.


![생각해야 될 원인균? 획득 경로 × 면역 4사분면 (슬라이드)](../../inputs/abx_figs/f1_quadrant.png)


**[기출]** 환자는 원인균을 얻은 곳이 community acquired(지역사회 획득)인지 nosocomial(병원 감염)인지, 면역이 competent(정상)인지 compromised(저하)인지로 나눈다.


이 원리를 약 선택에 대 보자. 같은 65세 남성이 발열과 의식저하로 세균성 뇌수막염이 의심되어도, 획득 경로에 따라 약이 달라진다.


따라서 감염 장소가 생각할 균을, 생각할 균이 약을 정한다. 만나는 장소(입원실, ICU, 개원 진료실)가 그 맥락을 알려 준다.

- **개념 Check** 개두술 7일 뒤 뇌수막염 증상을 보이는 18세 남성은 community acquired / compromised로 평가한다. (O, X) → X — nosocomial / competent이다.


<a name="chapter-2"></a>

## 2장. 경험적 치료에서 표적 치료로: 치료 과정, 정균제와 살균제, 환자 인자

<a name="topic-6"></a>

### 1. 경험적 치료(empiric)는 언제 표적 치료(targeted)로 바뀌나?

**핵심 답**

- 감수성 검사로 균과 감수성이 확인되면 바꾼다. 바꿀지 판단할 때 가장 중요한 것은 치료 반응이다.


경험적 치료는 원인균을 모르는 채 시작한다. 그럼 균이 확인된 뒤에는 어떻게 바꿀까? 치료는 환자 평가에서 증상과 징후를 확인하는 데서 시작해, 경험적 치료, 감수성 검사, 표적 치료, 모니터링의 다섯 단계로 이어진다.


![항균제 치료의 흐름](diagrams/diagram_02.png)


경험적 치료를 시작하면서, 치료 전에 채취한 혈액 등의 검체로 감수성 검사(susceptibility test)를 함께 한다. 이 검사로 균이 동정되고 항균제별 감수성과 MIC(Minimum Inhibitory Concentration, 최소 억제 농도)가 나오면, 그 결과를 보고 지금 환자에게 가장 알맞은 약으로 바꾸는 것이 표적 치료(definitive therapy)다. 다만 경험적 치료가 이미 적절하다면 그대로 유지하는 것이 가장 좋고, 바꿀지는 다음 다섯 가지로 판단한다.

- 감염 부위, 원인균, 감수성 패턴, 숙주(환자) 인자, 치료 반응(가장 중요)

지극히 상식적인 흐름이지만 실제로 지켜지지 않는 경우가 있어 기초부터 설명했다.

- **개념 Check** 감수성 검사는 표적 치료로 바꾼 뒤에 검체를 채취해 시행한다. (O, X) → X — 치료 전 검체로 경험적 치료와 동시에 한다.


<a name="topic-7"></a>

### 2. 정균제(bacteriostatic)와 살균제(bactericidal)는 언제 쓰나?

**핵심 답**

- 면역이 약하거나 중증 감염이면 살균제를 쓴다.


![Bacteriostatic vs bactericidal agent: 약을 넣은 뒤 살아 있는 균 수 (슬라이드)](../../inputs/abx_figs/f2_static_cidal.png)


다만 정균과 살균은 항균제의 농도나 균주에 따라 달라질 수 있는 상대적인 개념이다. 그리고 면역 상태는 살균제를 고르는 기준이면서 용량을 바꾸는 환자 인자이기도 해서, 다음에 환자 인자를 본다.

- **개념 Check** 면역억제 환자에서는 정균제보다 살균제를 사용해야 한다. (O, X) → O


<a name="topic-8"></a>

### 3. 환자 인자(면역, 신·간기능, 저관류, 연령)는 용량을 어떻게 바꾸나?

- 환자 인자는 네 가지다. 앞에서 본 면역 상태가 첫째다.
- 즉 같은 감염이라도 면역, 제거 장기, 혈류, 나이에 따라 용량이 달라진다.
- **개념 Check** 신기능이 떨어진 환자에서는 신장으로 제거되는 항균제의 혈중 농도가 낮아진다. (O, X) → X — 혈중 농도가 올라가 독성 위험이 커진다.


<a name="chapter-3"></a>

## 3장. 항균제 용량, 용법, 투여 경로의 결정

<a name="topic-9"></a>

### 1. 정해진 항균제 용법은 무엇을 근거로 하나?


1장에서 본 감염 장기와 환자 요인을 이번에는 용량, 용법, 투여 경로를 정하는 눈으로 다시 본다. 교수님은 영상의 두 번째 질문(질문2)에서 실제 중요한 내용이 많이 나왔다고 했다. 질문2의 답은 세 가지다. 어느 기관의 감염인가, 어떤 환자인가(외래, 입원, 중환자), 그리고 IV와 PO(경구) 중 무엇인가. 셋째는 오랫동안 고민되어 온 문제다. 아래 세 소절이 이 순서다.

- **개념 Check** 항균제의 표준 용법은 표적 균주의 MIC와 PK/PD 자료, 임상시험을 근거로 정해졌다. (O, X) → O


<a name="topic-10"></a>

### 2. 감염 기관(CNS, 안구, 뼈·관절, 호흡기)에 따라 투여 경로는 어떻게 달라지나?

- 즉 약은 혈중이 아니라 균이 있는 곳에서 충분한 농도여야 한다.
- **개념 Check** Aminoglycoside는 요로에서 혈중보다 훨씬 높은 농도로 존재한다. (O, X) → O


<a name="topic-11"></a>

### 3. 환자 사정(외래·입원, 혈관, 흡수, 순응도)에 따라 투여 경로는 어떻게 달라지나?

- 즉 경로와 횟수는 약효만이 아니라 환자의 사정으로도 정한다.
- **개념 Check** 하루 1번 복용하는 항균제는 바쁜 환자의 순응도를 높여 치료 농도 유지에 유리하다. (O, X) → O


<a name="topic-12"></a>

### 4. 주사(IV)가 경구(PO)보다 항상 효과적인가?


IV는 100% 들어가지만, 맞는 경로는 감염이 어디에 있느냐에 따라 다르다. 대표적인 예외가 장 안의 감염이다. Clostridium difficile 감염(CDI)과 amebic colitis에는 흡수되지 않고 장관 안에 고농도로 머무는 luminal agent를 쓰고, 경구 vancomycin이 그런 약이다. 그래서 CDI에는 IV vancomycin이 아니라 경구 vancomycin이 맞다.

- **개념 Check** CDI에서 경구 vancomycin은 흡수되지 않고 장관 안에서 작용한다. (O, X) → O


<a name="chapter-4"></a>

## 4장. PK/PD에 따른 용법, 투여 경로 원칙, 병용요법

<a name="topic-13"></a>

### 1. 시간 의존성과 농도 의존성 살균(PK/PD)은 용법을 어떻게 정하나?

**핵심 답**

- 시간 의존성은 MIC 위에 오래 머물수록, 농도 의존성은 잠깐이라도 높이 올라갈수록 유리하다.


3장에서 약이 닿는 길을 정했다. 이제 간격과 용량을 정하는 원리를 본다. 교수님은 이 PK/PD 슬라이드가 중요하다고 했다. 핵심은 혈중 농도 곡선을 MIC와 견주는 것이다. MIC 위에 얼마나 오래 있나, 얼마나 높이 올라가나에 따라 약의 작용 방식이 갈린다.


![Time-dependent antibiotics (왼쪽) / Concentration-dependent antibiotics (오른쪽) (슬라이드)](../../inputs/abx_figs/f34_time_conc.png)


**[기출]** 시간 의존성(time-dependent killing) 약은 MIC 위에 오래 머물수록 잘 들어 저용량을 짧은 간격으로 주고, 농도 의존성(concentration-dependent killing) 약은 잠깐이라도 높이 올라갈수록 잘 들어 고용량을 긴 간격으로 준다. **[기출]** 농도가 MIC 아래로 내려가도 항균 효과가 바로 0이 되지 않는 것이 PAE(post-antibiotic effect)다.


![PK/PD 지표별 약물: Cmax/MIC, AUC/MIC, T>MIC (슬라이드)](../../inputs/abx_figs/f5_pkpd_index.png)

- **개념 Check** Aminoglycoside는 time-dependent killing을 하는 대표 약물이다. (O, X) → X — 농도 의존성이다.
- **개념 Check** PAE는 항균제 농도가 MIC 이상일 때만 나타나는 효과이다. (O, X) → X — MIC 아래로 떨어진 뒤에도 지속되는 효과다.


<a name="topic-14"></a>

### 2. 투여 경로는 경구와 주사 중 무엇을 기본으로 정하나?

- PK/PD로 간격과 용량을 정했으면 마지막으로 경로를 확인한다.
- 즉 경로는 ‘더 센 것’을 고르는 일이 아니라, 약이 필요한 곳에 필요한 농도로 가는 길을 고르는 일이다.
- **개념 Check** 중증 환자도 가능하면 빨리 IV에서 경구로 바꾼다(IV → PO switch). (O, X) → O


<a name="topic-15"></a>

### 3. 항균제 병용요법(combination therapy)은 단일 제제보다 항상 나은가?

**핵심 답**

- 아니다. 단일 제제가 원칙이고, 근거가 뚜렷한 이득이 있을 때만 병용한다.


병용요법을 흔히 cocktail therapy라고 하지만 정식 표현은 combination therapy다. 칵테일이 단일한 술보다 늘 낫지 않듯 병용도 늘 낫지 않고, 개원가뿐 아니라 대학병원에서도 남용되는 측면이 있다. 사회가 고령화될수록 이 문제는 더 중요해진다.

- **개념 Check** 항균제는 여러 개를 병용할수록 효과가 더해진다. (O, X) → X — 상호작용으로 효과가 줄 수 있다.

### 4. QUIZ


**문제** 65세 남성이 뇌종양 수술 뒤 중환자실에 입원 중 세균성 뇌수막염이 의심된다. 가장 알맞은 경험적 항균제 조합은?

- ① ceftriaxone + vancomycin + ampicillin
- ② meropenem + vancomycin
- ③ 경구 vancomycin 단독
- ④ aminoglycoside 흡입 치료
- ⑤ 감수성 결과가 나올 때까지 항균제를 쓰지 않는다

<details>
<summary>정답과 해설</summary>

**정답:** ② meropenem + vancomycin

- ① 건강하던 사람의 community acquired 뇌수막염 조합이다
- ② 병원 감염이므로 Pseudomonas를 고려한다 (정답)
- ③ 경구 vancomycin은 흡수되지 않는 luminal agent다
- ④ 흡입 치료는 호흡기 감염의 선택지다
- ⑤ 경험적 치료는 감수성 검사와 동시에 시작한다

</details>


**문제** 투여 경로에 대한 설명으로 옳지 않은 것은?

- ① 외래에서는 경구 투여가 가장 선호된다
- ② 중증 환자도 가능하면 빨리 IV → PO로 바꾼다
- ③ 입원 환자에게는 주사가 항상 더 효과적이다
- ④ 경구로 적정 혈장 농도를 얻을 수 없으면 주사를 고려한다
- ⑤ 패혈증처럼 긴급한 경우에는 비경구 투여를 우선한다

<details>
<summary>정답과 해설</summary>

**정답:** ③ 입원 환자에게는 주사가 항상 더 효과적이다

- ① 스스로 먹을 수 있다
- ② 가능한 한 빨리 경구로 바꾸는 것이 유리하다
- ③ 주사가 늘 낫지는 않다. CDI에는 경구 vancomycin을 쓴다 (정답)
- ④ 흡수, bioavailability 문제 때문이다
- ⑤ 긴급한 항균 치료가 필요하다

</details>
