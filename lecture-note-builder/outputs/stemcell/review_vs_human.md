# 줄기세포 강의록 — 사람이 쓴 정리본(MOM) vs 프로그램 산출물 평가

- 사람 작성본: `20261012 2교시 … MOM.docx` (9쪽, 본문 약 1.3만 자, 이미지 15장)
- 프로그램 산출물: `outputs/stemcell/stemcell_강의록.pdf` (11쪽, 약 2.8만 자, 이미지 15장 재사용 + 개념 Check 15 + 퀴즈 2)
- 입력이 다르다: 사람은 슬라이드·수업 현장을 보고 썼고, 프로그램은 **음성 변환 스크립트 + 슬라이드 이미지 + PAD**만 받았다. 사람 작성본의 글은 이번 생성에 쓰지 않았다(이미지만 사용). 아래는 생성 후 비교한 평가다.

### 2-2. 사람이 뺐거나 줄인 것 (프로그램은 넣음 — 과잉 가능성)
- 치료제 역사의 연도(1890년경, 100년·30년·15년 간격), 항체·CAR-T 상세, 야마나카 일화(2006 Cell, 2012 노벨상), 한국 MSC 4개 허가와 허가 거부 표, Neuronata-R 상세(2,000억·주가), ‘dead end’ 비유와 1회 2,000만 원, T2 mapping·medial compartment 상세, 경쟁사 목록, 비글·돼지 실험 세부, 일본 연구자 이름.
- 사람은 이를 **한 줄 또는 생략**으로 처리했다. 시험·복습 관점에서는 사람의 선택이 맞다. 프로그램은 **빠짐없이 넣고 압축형 형식으로만 줄였다.** → ‘내용 보존’ 원칙과 ‘복습 효율’ 사이의 조정이 필요하다 (아래 4-1).

### 2-3. 사실 대조
| 항목 | 사람 | 프로그램(스크립트 기준) | 판단 |
|---|---|---|---|
| IND 허가 시기 | **2024년 8월**, “IND 과정에 3년” | **2023년 8월 1일**, 이후 “2025년 작년에 3명 투여” | **불일치 — 확인 필요.** 음성 변환(ASR) 오류일 수 있고 사람은 슬라이드를 봤을 수 있다. 프로그램은 스크립트 그대로 적고 경고를 달지 않았다 |
| 골관절염 ‘중간단계’ | 10–20년 | 약 20년 | 스크립트는 “대략 한 20년”. 슬라이드 확인 필요 |

**프로그램의 사실 오류는 발견하지 못했다.** 단, 위 IND 날짜처럼 **출처 간 불일치를 스스로 잡지 못한 것**은 결함이다.

## 3. 평가 요약

| 관점 | 평가 |
|---|---|
| 정확성 | 스크립트 범위에서는 정확. 사람은 슬라이드 정보를 더 쓸 수 있어 **날짜·범위 일부가 다름** — 불일치 탐지 기능 없음 |
| 완전성 | 프로그램 ≫ 사람 (사람은 의도적 생략) |
| 복습 효율 | 사람 ≥ 프로그램 — 압축, 슬라이드 순서 일치, 시험 신호 제공 |
| 시험 신호 | **사람 ≫ 프로그램** (강조 여부·빈출·PAD 이력) |
| 능동 학습 | 프로그램 ≫ 사람 |
| 가독성 | 사람은 글이 적고 표 중심, 프로그램은 상자·박스가 많아 **쪽당 밀도가 높다** |
| 파랑 규칙 준수 | 둘 다 준수. 사람의 “PAD:” 꼬리표는 출처 투명성이 높다 |

총평: **내용 보존·학습 장치는 프로그램이 낫고, 시험 신호·압축·논리 연결·슬라이드 구조 대응은 사람이 낫다.** 가장 큰 격차는 “무엇이 시험에 나오고 무엇을 안 외워도 되는가”라는 **판단 정보**다. 이 정보는 PAD 해설(작성자 코멘트)과 연자의 발언에 일부 있었지만 프로그램이 **쓰지 않았다**.

## 4. 개선 제안 (일반화 가능한 것만)

### 4-1. 시험 신호 층 — 가장 큰 격차
1. **PAD 해설의 시험 신호를 파싱**: “작년 출제예고”, “이번에 강조한 부분은 아닙니다”, “(2019년 짤)”, “저희는 ○○ 배운 적 없습니다” → 문항별 `signal`(출제예고 / 강조 안 함 / 미수업 / 족보 반복)을 `ExamItem`에 저장.
2. **표지 코멘트 자동 초안**: PAD 연도별 출제 이력(몇 년 연속 같은 테마, 새 문제 여부), 올해 강조 여부, 빈출 주제를 한 단락으로 — **사실로만**(근거 문항 번호 표기), 예상·추측은 작성자 몫으로 비움.
3. **노력 꼬리표 자동 제안**: 문항 신호가 “미수업”이면 해당 내용에 `참고`, “출제예고”이면 `필수` 후보.

### 4-2. PAD 표시
4. **파랑 문장에 출처 꼬리표** 옵션(`[기출 2021]`), 수업에서 안 나온 PAD 사실은 `Only PAD`로 분리 표시. 구현: `Statement`의 PAD 참조가 스크립트 참조 없이 PAD만 있을 때 자동으로 `Only PAD` 꼬리표. ⛔ 파랑 규칙은 그대로.
5. 수업에서 다루지 않은 PAD(이번 recapitulation·신장 오가노이드)는 **사람처럼 생략을 허용**하되 리포트에는 남긴다(현재는 Reference로 강제). → 사용자 선택 옵션 `--uncovered-pad {reference,omit}`.

### 4-3. 구조·서술
6. **연자의 파트 구조 보존**: 스크립트의 “Part 1/2/3” 발화를 장 제목 후보로 쓰는 단서(`outline`) 추가 — 슬라이드 구조와 노트 구조를 맞춘다.
7. **논리 연결 문장 규칙**: 표 뒤에 “따라서 …” 한 줄(결론 다리)을 쓰도록 스킬에 추가(예: 한계 → 선택). 작성자 추가분(`origin: author`)으로 표시.
8. **개념 구분 각주**: PAD 해설·교수 강조에서 두 용어가 대비되면(스페로이드 vs 오가노이드) `concept` 박스 1개 의무화.
9. **압축 수준 선택** `--density {complete,review}`: `review`는 일화·연도·상세 수치를 한 줄로 접는다(사람의 생략 패턴: 역사 연도, 한국 허가 표 상세, 경쟁사 목록, 일본 인명).

### 4-4. 검증
10. **출처 간 수치 불일치 경고** `SOURCE_CONFLICT`: 스크립트와 별도 자료(슬라이드·사람 정리본·PAD)에서 같은 개체의 연도·수치가 다르면 경고(이번 IND 2023 vs 2024). 단 **생성 입력으로 쓰지 않은 자료는 비교에 쓰지 않는다** — 사용자가 `--cross-check`로 명시한 자료만.
11. 음성 변환 오류 의심(연도·단위·고유명사)은 `verify`(보라)로 자동 표시: 같은 스크립트 안에서 모순되는 시점(“2025년 작년에”)이 있으면 경고.

### 4-5. 우선순위
| 순위 | 작업 | 이유 |
|---|---|---|
| 1 | PAD 해설 신호 파싱 + 표지 코멘트 초안 (4-1) | 가장 큰 격차, 입력이 이미 있음 |
| 2 | `Only PAD` / 출처 꼬리표 (4-2) | 출처 투명성, 구현 작음 |
| 3 | 개념 구분 concept 의무화, 연결 문장 규칙 (4-3) | 스킬 수정만으로 가능 |
| 4 | `--density review` | 사용자 선택 필요 |
| 5 | SOURCE_CONFLICT (4-4) | 입력 정책(교차 자료 허용 범위) 확인 후 |

## 6. 반영 결과
- 프로그램: PAD 해설 신호 파싱(`ExamItem.signals`), 표지 **기출 이력(PAD 집계)** 자동 표시, `prepare`의 `brief/exam_signals.md`, `[PAD …]` / `[Only PAD …]` 꼬리표(`pad_tags`, 압축형 기본), `--uncovered-pad {reference,omit}`, 스킬 11–15항(시험 신호·꼬리표·개념 구분 박스·연결 문장·미수업 기출). 미구현: `--density review`, 별도 자료와의 `SOURCE_CONFLICT`(교차 확인 허용 범위 정책 필요).
- 노트(12쪽, 오류 0): 표지 코멘트에 PAD 해설 기준 신호(2025년 2문항 ‘강조 안 함’, 줄기세포 종류 5문항·오가노이드 3문항), 스페로이드 vs 오가노이드 개념 정리 박스, ESC·MSC 한계 → iPSC 연결 문장, Ryoncil·iPSC 독성평가·오가노이드 모사의 **Only PAD** 분리, IND 날짜 확인 필요(보라) 표시.
