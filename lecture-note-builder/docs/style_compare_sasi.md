# 사시 MOM(박신혜 교수님, 감각기, 11쪽)과 우리 노트의 문체 비교

대상: 사람 MOM `사시`(2025-11-24) ↔ 우리 `노인정신질환 1`(19쪽), `신경안과`(12쪽). MOM 글은 비교 전용(생성에는 쓰지 않음).
측정: 줄바꿈을 이어 붙인 문장 단위(MOM 225개, geri 150개, 신경안과 117개). 도구: 이 문서 아래 스크립트 설명.

## 1. 문장 길이
| | MOM(사시) | 우리 geri | 우리 신경안과 |
|---|---|---|---|
| 평균 / 중앙값 | 46자 / 39자 | 46자 / 40자 | 59자 / 50자 |
| 25자 이하 | **32%** | 8% | 9% |
| 26~60자 | 40% | **70%** | 51% |
| 61자 이상 | 28% | 22% | **39%** |
| 합니다체 문장 평균 | 60자 | 52자 | 67자 |

- 평균은 비슷하지만 **분포가 다르다**. MOM은 *짧은 단정 줄*(32%: `정의 : 눈이 몰려 보이는 사시는 내사시입니다`, `① 억제 suppression`, `= Singly`)과 *길게 풀어 쓰는 설명 문장*(28%)이 섞인 두 봉우리이고, 우리 geri는 26~60자 한 봉우리에 몰려 단조롭다.
- 신경안과는 61자 이상이 39%라 한 문장에 사실이 둘 이상 들어 있다(눈으로 읽기 무거움).

## 2. 종결어미
| | MOM | geri | 신경안과 |
|---|---|---|---|
| ~합니다/습니다 | 54% | 69% | 71% |
| ~해요/죠/네요 (구어) | **8%** | 1% | 1% |
| 명사·기호 종결 (`= x`, `→ y`, 라벨) | **35%** | 28% | 25% |
| 개조식 -함/-음 | 2% | 1% | 2% |
| 한다체 -다 | 1% | 1% | 2% |

- MOM의 구어(8%)는 **세 자리**에서만 나온다: ① 환자 입장 제목(`눈이 너무 몰려있어요`, `가끔 초점이 흐릿해져요`), ② 괄호 안 여담·교수님 말 전달(`(눈돌출이 특징적이죠)`, `~다고 하네요`), ③ 독자에게 말 걸기(`기억하세요!`, `이해하시면 될 것 같습니다`, `정상 양안시를 갖고 계시네요!`). 본문 설명은 합니다체.
- 우리는 구어가 거의 없고(1%) 모든 문장이 같은 거리에서 말한다. 합니다체 비중이 높고(약 70%) 라벨·기호 줄이 적다.

## 3. 교수님 강조점을 풀어쓰는 방식
MOM은 강조를 **네 가지 층**으로 나눠 쓴다. 우리는 ‘~라고 강조하셨습니다’ 한 가지 층뿐이다.

| 층 | MOM의 방식 (예) | 우리 |
|---|---|---|
| ① 표지 안내 | 작성자 코멘트에 ‘superficial하게 공부하면 되고 deep하게 팔 필요 없다고 하셨습니다’, ‘강조점 위주(★)로 빠르게 보시고, 파드는 참고만’ — **공부 범위(깊이)** 를 말해 줌 | 없음. 강조 문장만 있음 |
| ② 본문 속 핵심어 | 일반 설명 문장 안의 **핵심 구만 빨강+굵게**(`약시에 취약하여 Critical하므로 빠른 치료가 필요`). 문장 전체를 빨갛게 하지 않고, ‘강조하셨다’는 말도 붙이지 않음(12곳 이상) | 문장 끝에 ‘~라고 강조하셨습니다’를 붙이고 **문장 전체**를 빨강 |
| ③ 태그 | `(강조)`, `★`(14개, 제목·정의·치료), 상자 안 `기억하세요!`, `머리 기울이는 사시 = trochlear n. 마비에 의한 SO 마비` | ★ 15개, 태그 없음 |
| ④ **약한 비중** | 회색 괄호로 **덜 중요함·안 나옴**까지 알려 줌: `(PPT, 언급X)`, `(아래는 설명X)`, `짧게 설명하고 넘어가셨습니다`, `(프리즘 개념은 중요하지 않아 보입니다)`, `수술명은 전혀 몰라도 될 것 같습니다`, `(처음에도 강조하셨죠)` | 없음(9회 vs 0회) |

- 풀어쓰는 모양: MOM은 **‘~라고 하셨습니다’를 시험 범위와 공부 깊이 정보에만** 쓰고(5회), 그 외 강조는 색·굵기·★로 보여 준다. 우리는 강조를 항상 문장으로 풀어 써서 본문이 무거워지고 강조 문장이 서로 비슷해 보인다.
- 사실 단정 문장과 교수님 말 전달이 한 문장에 섞이지 않는다: 설명은 합니다체 평서문, 교수님 말은 **괄호 안 짧은 한 줄**.

## 4. 승인된 규칙 (사용자 승인, `style_rules/approved_rules.md` L35~L40)
| 규칙 | 내용 | 근거 |
|---|---|---|
| **L35 (C1) 강조 층 나누기** | 교수님 강조를 (가) 일반 문장 안 핵심구는 빨강+굵게만, (나) ‘~라고 강조하셨습니다’는 시험 범위·공부 깊이에만, (다) 소절 제목·정의는 ★. L6 v2를 보완 | 3절 ②③ |
| **L36 (C2) 약한 비중 표시** | 교수님이 넘어가거나 안 나온다고 한 곳은 회색 괄호 한 줄: `(짧게 설명하고 넘어가셨습니다)`, `(시험에 나오지 않는다고 하셨습니다)`. 스크립트에 근거가 있을 때만 | 3절 ④ |
| **L37 (C3) 표지 공부 깊이 안내** | 작성자 코멘트에 ‘어디까지 공부하면 되는지’ 한 문단 + `meta.tips`에 같은 내용 | 3절 ① |
| **L38 (C4) 문장 길이 두 봉우리** | 단정 줄(25자 이하) 30% 안팎, 풀어쓴 설명 문장 25% 안팎. 61자를 넘는 문장은 사실 하나씩 둘로. 검사 `SENTENCE_TOO_LONG`(경고, 61자+가 30% 초과) | 1절 |
| **L39 (C5) 구어 허용 자리** | 해요체·구어는 (가) 환자 입장 소절 제목, (나) 괄호 여담, (다) 독자 안내(`기억하세요!`)에만. 본문 설명은 합니다체 유지(L5 v2와 충돌 없음) | 2절 |

| **L40 단어 강조 2단계** | ① 맥락상 주요 단어 = 굵게 `**x**` ② 반드시 알아야 할 중요한 단어·개념 = 판단하여 **빨강+굵게** `{k|x}`, 한 쪽 5개 안팎(글자 위 점은 쓰지 않음)(소절당 8개 이하, 검사 `KEY_EMPHASIS_TOO_MANY`) | 사용자 지시 |

검사: 문장 길이 `SENTENCE_TOO_LONG`(61자+ 문장이 30% 초과), 빨강+굵게 `{k|…}` 과다 `KEY_EMPHASIS_TOO_MANY`(`app/write/mom_format.py`). 글자 위 점(강조점)은 쓰지 않는다.
