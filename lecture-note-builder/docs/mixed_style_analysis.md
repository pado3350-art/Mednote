세 노트 모두 한 강의 안에서 모양을 바꾼다. 같은 강의에서도 **개념·기전 부분은 문단, 절차·원인·소견 목록은 표와 목록**으로 쓴다. 이것을 기본 규칙 L10으로 삼았다.

## 1. 모양을 고르는 기준 (L10)

| 내용 | 사람 노트의 모양 | 예 |
|---|---|---|
| 기전, 원리, "왜" | 문단 2~4개, 인과 연결어 | high grade의 cellularity → angiogenesis → necrosis (영상 2) |
| 병리 | 문단 | ARAS가 각성을 유지하는 방식 (혼수) |
| 임상 판단 | 문단 + "그러나 / 그럼에도 불구하고" | CT가 정상이어도 요추천자를 해야 하는 경우 (혼수) |
| 감별 소견, 특징 | 번호 목록 + 한 마디 풀이 | extra-axial 소견 4가지 (영상 2) |
| 조건 → 처치, 원인 분류 | 2열 표 | 저혈당이면 50% 포도당 50 ml, 원인별 분류 (혼수) |
| 비교 | 표 (영상 \| 특징 \| 소견) | high grade 특징 4가지 (영상 2) |
| 단계 구분 | 표 | alert / drowsy / stupor / coma |

프로그램 구현: `Topic.style`(explain | list), `templates/mom_mixed.yaml`(`mixed: true`), `app/write/mixed.py`(제안과 검사), `prepare`가 만드는 `brief/style_plan.md`.

## 2. 세부 서술 기법 (L11–L14)

**L11 정의 → "그럼" 추론.** 정의 다음에 바로 따라 나오는 결론을 한 문장으로 끌어낸다.
> Glia는 non-neural cells이며 … 가 속합니다. 그럼 brain tissue니까 intra-axial tumor가 생기겠네요.

**L12 기전 사슬 + "따라서" 한 줄.** 문단으로 인과를 풀고 마지막에 화살표 한 줄로 묶는다.
> 세포가 빽빽해 cellularity가 높습니다. → 신생 혈관이 많이 생기면 → 잘 터지고 … necrosis가 잘 발생합니다.
> 따라서 high grade tumor는 cellularity가 높고 → angiogenesis가 활발하며 → necrosis가 많이 보입니다.

**L13 원리 → 사례 적용, 대조.** 원리를 먼저 세우고 사례마다 원리를 다시 부른다. 표 앞에는 읽는 법 안내를 둔다.
> grade 2 tumor는 cellularity가 높은 특징까지만 있으므로 necrosis나 hemorrhage가 없습니다.
> 앞선 glial tumor와 달리 CNS 림포마는 ① severe edema ② CBV 정상 … 이는 neo-angiogenesis를 하지 않기 때문입니다.
> (표 앞) 먼저 4가지 특징을 설명을 통해 이해하시고, 각각에 유용한 영상을 매치해보세요.

**L14 "용어: 정의 + 한 마디".** 목록 항목에 쉬운 풀이나 이유를 붙인다.
> Buckling of gray and white matter interface : 경계에서 뾰족하게 확 휘어짐
> Overlying bony change : 뼈에 변화가 생기면 extra-tumor의 가능성이 높습니다. dura 바로 바깥이 뼈니까요

## 3. 따르지 않은 것

- **어미.** 세 노트는 합니다·요체를 많이 쓴다(신경영상학 "니다." 114회). 사용자는 2026-11-10에 L5를 합니다체로 바꾸도록 승인했다(L5 v2). 이 분석 당시에는 한다체였다. 추론 문장은 "생기겠네요" → "생깁니다"로 쓴다.
- **색.** 이 노트들은 다른 교수님 파드도 파랑으로 칠했다. 이 프로그램은 파랑 = 해당 PAD 전용 규칙을 유지한다.
- **"교수님이 헷갈려하신다" 같은 평가 문장.** 표지 코멘트에서만 쓰고 본문에서는 쓰지 않는다(L6).
