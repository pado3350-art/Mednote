# 모범 예시 분석 — “Nucleotide Biosynthesis (2)” MOM (27쪽) vs 우리 프로그램 산출물

- 분석 대상: `20221207 3교시 생화학 이정화 교수님 Nucleotide Biosynthesis(2)` 정리본 PDF (27쪽, 마지막 1쪽은 빈 쪽)
- 비교 대상: `outputs/tcell_v2`(스토리형 상세), `outputs/precision`(스토리형 상세, 38쪽), `outputs/precision_compact`(압축형, 12쪽)
- 원본 PDF는 비공개 자료라 저장소에 넣지 않았다. 아래는 쪽 번호로 근거를 단다 (p.n = PDF 쪽).
- 표지 맨 아래 작성자 전화번호 등 개인정보는 분석·학습 대상에서 제외한다.

## 2. 서술 방식 — 관찰된 기법 12가지

| # | 기법 | 예시 (쪽) |
|---|---|---|
| 1 | **독자를 부르는 구어체 + 질문으로 끌고 가기** | “RR이 계속 일하기 위해서는 에너지를 받아야 하겠죠?”(2), “그럼 Thioredoxin도 다시 reduction 시켜줘야 반응이 유지되겠죠?”(11), “쉽죠?”(2) |
| 2 | **의인화·은유로 기전을 한 장면으로** | 항암제 = “스파이”, “멍청한 enzyme은 uracil인 줄 알고 열심히 합성하다가 스파이에게 잡혀…”, “자살로 끝나는 슬픈 엔딩, suicide inhibition”(2), R2 = “전자 셔틀”, “손님(substrate)이 active site로 들어오면”(9), “시발점은 국밥 같은 NADPH”(2) |
| 3 | **약어·기호를 외우기 쉬운 문장으로** | RR의 R2개 = “R이 2개인 것을 닉값 하듯”(2), “Purine은 ring 안 풀리고 pyrimidine만 풀립니다”를 ★ 한 줄로(19) |
| 4 | **시험 비중·노력 수준을 문단마다 말해 준다** | “올해는 1분만 같이 오늘 보고 다시 안 봐도 된다고 하셨습니다”(9), “외우실 필요 없대요~”(7), “들어만 놓으라고 하셨습니다”(21), “진짜 이거 맨날 나와요”(5), “이름 정도만 알아두라고 하시네요”(17) |
| 5 | **교수님 인용은 ‘출제 단서’에만** | 내용 설명 문장에는 “교수님은” 없음. 단서는 괄호·종결형(“~하시네요”)으로 한 번만 |
| 6 | **괄호 속 작성자 목소리** (원문 vs 작성자 추가 분리) | “(재밌으니까 한 번 읽어만 보세요..)”(9), “(이것도 1분만 보고 가셨는데 안나온다는 말은 안하셨습니다 ㅠㅠ)”(11), “(그림 우측 하단에 CTP가 아니라 CDP라고 합니다.)”(16) ← **슬라이드 오류 정정도 괄호** |
| 7 | **기전은 번호 단계 + 마무리 요약 한 줄** | 1)–6) 단계 후 “이렇게 6단계를 거쳐 ribonucleotide는 deoxyribonucleotide가 되었습니다. … 단 하나, 2개의 Cys 사이의 disulfide bond 빼고요”(10) |
| 8 | **그림을 가리키며 읽게 한다** | “위의 사진에서 Tyrosyl radical 구조를 확인해 보세요”(8), “위 그림 우측 하단의 화살표를 확인해 주세요”(16), “(파란 박스는 Ser, 초록 박스는 Gly)”(12) |
| 9 | **★ 줄은 ‘예외·덧붙임·핵심 한 줄’ 전용** | ★ AMP는 phosphate보다 deamination 먼저 가는 경로도 있다(18), ★ Guanine·Hypoxanthine은 salvage에 재사용(18) |
| 10 | **시간 간 연결 표시** | “(2교시 애플 참조!)”(14), “(지난 시간에 공부한 근육에서의 경로…)”(18), “앞의 교시에서 다룬 내용은 ribonucleotide였는데 이제는 deoxy form이…”(6) |
| 11 | **‘개념 정리’ 회색 박스**로 용어 대비 한 번 더 | “Uracil과 Thymine”(11) — 본문 문단 뒤에 정의를 박스로 반복 |
| 12 | **가벼운 장난 레이어** (취소선·농담) | 취소선으로 “ATP에는 d가 안 붙었으니까”(8)·농담(3, 5), 표지 코멘트에 “취소선 친 거는 그냥 제가 외우는 방법이니 가볍게 무시해주세요” → **필수 내용과 암기 팁을 서식으로 분리** |

## 3. 쪽마다 있는 **‘개념 Check’ 사이드바** (가장 큰 차이)

- 거의 모든 본문 쪽 왼쪽 여백에 **그 쪽 내용만으로 풀 수 있는 O/X 또는 단답 1–2문항**이 있고, 쪽 아래 **정답 상자**가 있다(예: p.7 “RR은 ATP에는 결합하지만 GDP에는 결합하지 않는다 (O,X)” → 정답 X).
- 첫 문장은 항상 그 쪽의 **한 줄 요약**이다(p.6 “Ribonucleotide가 deoxyribonucleotide로 변하는 과정에서는 ribonucleotide reductase가 사용된다.”).
- 본문을 읽으면서 **바로 인출 연습**이 된다 → 마지막 QUIZ는 이를 종합한다.

## 4. 색·서식 사용 (예시 안에서 관찰된 것)

- 빨강 = 교수 강조·꼭 외울 것(예: p.2 “Phosphate는 딱 2개만”, p.19 “Adenosine deaminase와 Xanthine Oxidase”).
- 파랑 = 내용 GUIDE·PBL GUIDE에서 **시험·PBL 핵심으로 반복되는 항목**으로 쓰인 것으로 보인다(**범례는 PDF에 없음** → 정확한 규칙은 확인 불가. 우리 프로젝트의 ‘파랑 = PAD 기출’ 규칙과 다를 수 있으므로 따라 하지 않는다).
- 굵게 = 용어·결론 문장, 취소선 = 작성자 사견·암기 팁, 회색 박스 = 개념 정리.

## 6. ⚠️ 사용자 문체와의 충돌 — 그대로 따라 하면 안 되는 부분

사용자가 직접 고친 문장(`my-writing-style`)은 **합니다체 → 한다체, 교수님 인용 삭제, 군더더기 삭제**였다. 예시는 그 반대로 **합니다체·구어·교수님 언급(출제 단서)** 이다.
→ **다른 작성자의 문체이므로 문체 규칙은 가져오지 않는다.** 가져올 것은 *문체와 무관한 구조·기법*(A1, A2, A3, A5, B1, B2, B5, B6)이다.
→ 비유(A4)·괄호 사견(A5)·독자 호출은 **어미와 독립적으로** 한다체로도 쓸 수 있다(“스파이처럼 생긴 5-FU를 효소가 uracil로 착각한다”).
→ 최종 판단은 사용자 승인이 필요하다: 아래 `learn-mednote-style` 규칙과 같은 절차로, **이 예시에서 어떤 기법을 채택할지 사용자가 고른 것만** 스킬에 반영한다.

### 6-1. 따라 하지 않을 것 (예시의 약점)
- 표지에 **작성자 전화번호** (개인정보).
- 오탈자·내부 불일치: `lybose`, `utric acid`, 목차 VI·VII 모두 `16p`, 본문 일부 ‘CTP/CDP’ 정정이 괄호로만 남음.
- 특정인 이름을 쓴 농담(p.3 취소선 줄) — 공유 문서에는 부적절.
- 쪽 하단 대량 여백(p.14, 25, 26) — 그림 크기 고정 때문. 우리의 `figure_side`가 더 낫다.
- 슬라이드 스크린샷을 그대로 크게 넣는 방식 — 가독성은 좋지만 분량이 늘어난다(압축형에서는 줄여야 함).

### 검증 방법
1. 구현 후 `precision_compact`를 다시 만들어 **쪽당 check 수, 앞쪽 층 비율, effort 꼬리표 수**를 리포트에 찍는다.
2. 사용자에게 한 섹션(예: Oncotype DX)을 예시 방식으로 쓴 시안을 보여 주고 **문체(한다체/합니다체)와 기법 채택 여부**를 먼저 확인받는다.

## 8. 반영 결과 (사용자 승인: “서술 기법을 반영해서 업데이트”)

**⛔ 파랑 = 기출(PAD) 전용은 그대로.** 새 기능은 파랑을 쓰지 않고, 파랑이 들어가면 `BLUE_WITHOUT_PAD`로 막는다(`tests/test_techniques.py`). 어미는 한다체 유지.

| 제안 | 구현 |
|---|---|
| A1 개념 Check | `Statement.kind="check"` (문장 + `answer` O/X + `left_title` 한 줄 요약 + `explanations[0]` 이유). 같은 §의 check는 한 상자로 묶이고, 정답은 § 끝 정답 상자에 한 줄로. 검증 `CHECK_BAD_ANSWER`, `CHECK_NOT_GROUNDED` |
| A3 노력 단서 | `Statement.effort` 필수(빨강)/이해(검정)/참고(회색) 꼬리표. `prepare`가 `brief/effort_cues.md`로 교수 발언의 단서 후보를 뽑는다 |
| A5 작성자 추가분 | `origin="author"` → 회색 괄호, 출처 없어도 통과(파랑은 여전히 PAD 필요) |
| A4/B2/B1 비유·기전·그림 지시 | 스킬 `readable-note-organizer` 0b절 규칙 (작성자 추가분으로 표시, 기전 번호 단계 + 마무리 한 줄, 그림 지시 문장) |
| B5 개념 정리 박스 | `kind="concept"` |
| B6 퀴즈 해설 | `quiz.explanations` |
| 쪽 예산 | `page_budget`이 check 8개당 1쪽 + QUIZ 1쪽을 추가로 허용 |
| 미구현 | B3(시간 간 연결 자동 생성), B4(쪽 헤더 교시 라벨), C1(암기 팁 전용 서식) |
