# 사람이 쓴 MOM 분석 4 — 두부 외상 (2025-08-20, 신경계, 조광욱 교수님)

근거 자료(비공개, 저장소에 넣지 않음): 30쪽 = 서로 다른 팀의 노트 두 부(1~15쪽 병리·영상, 16~30쪽 골절 뒷부분 등). 쪽당 큰 그림 4.1개의 **그림 중심** 노트다.
항균제 노트와 **내용은 다른 강의**라서 문체·서술·전개 방식만 비교했다(MOM 글은 비교 전용, 생성에는 쓰지 않음).

## 1. 이 MOM의 문체·전개 (관찰)
| 특징 | 예 |
|---|---|
| 첫 쪽: 작성자 코멘트 상자 + 시험 포인트를 굵게 + 이번 시간 목차 | ‘CT에서 경막외출혈…을 구분하는 것은 매우 중요’ |
| 그림마다 **볼 곳을 짚는 글**: 그림 옆이나 아래에 1~3문장 | ‘오른쪽 사진을 보면…’, ‘왼쪽 CT의 화살표를 보면…’ |
| 정의 한 줄 + 콜론 뒤 한글 풀이 | ‘Primary injury: …  : 외부 충격을 받음과 동시에 뇌가 손상되는 것’ |
| 기전은 → 사슬 | ‘glutamate ↑ → Ca influx → 미토콘드리아 손상 → cell death’ |
| 번호·기호 계층 | Ⅰ(장) → 회색 띠 1. → 1) → ①② + 굵은 용어(영어) |
| 색: 빨강 = 교수님 강조, 파랑 = 기출, 회색 = 덜 중요한 슬라이드 글, 밑줄 = 핵심 | |
| 읽는 속도 안내 | ‘아래 정도만 언급하셨습니다… 가볍게 읽고 넘어가 주세요’ |
| 임상 장면 한 줄 | ‘5세 아이의 suture가 1mm?? 정상!’ |
| 합니다체 + 교수님 전언(‘~라고 하셨습니다’, 1000자당 약 3회) | |
| 문장 평균 약 60자, 질문 1000자당 0.8개 | |

## 2. 우리 규칙과 맞는 것 / 충돌하는 것 (판단)
- **채택**: 그림 해설 문장, 빨강 강조 누락 점검, 수치 비교 방법(아래 3). 이미 같은 방향: 기출 파랑, 표 정리, 전체 지도, 기전 사슬.
- **합니다체 본문**: 2026-11-10 사용자가 L5를 합니다체로 바꿔 채택(L5 v2). **채택하지 않음**: 잦은 ‘교수님께서 ~하셨습니다’ → L6(교수 발언 인용형 금지)이 그대로 유효. 쪽당 글자·글자 크기·쪽수 비교 → 그림 중심 강의와 텍스트 중심 강의는 비교 대상이 아니다.
- **이미 충족**: 문장 평균 45자(MOM 60자 이하), 본문 질문 2개(0.3/1000자, MOM 0.8), 합니다체 본문(L5 v2 적용 후).

## 3. 규칙 (2026-11-10 사용자 승인: L22 그림 해설, L23 빨강 누락 점검, L24 그림 중심 MOM 비교, L5 v2 합니다체)
1. **그림 아래 한 줄 해설**: 그림 뒤에 ‘무엇을 보라’는 1~2문장을 둔다. 같은 내용이 바로 위 표에 있으면 표 행을 옮겨서 한 번만 쓴다.
2. **빨강 누락 점검**: 스크립트의 ‘중요하다·꼭·기억’ 발언을 찾아 노트의 빨강과 맞춰 본다(항균제 노트에서 3곳 누락 발견, 추가).
3. 그림이 중심인 MOM과는 글자 밀도를 비교하지 않는다(`compare-mom`이 자동으로 생략).
