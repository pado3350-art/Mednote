# 긴 강의 정리 지침 (long lecture)

슬라이드 80장 이상, 발화 25¶ 이상, 또는 2교시 연속 강의는 **긴 강의**로 본다(`meta.long_lecture: "true"`).
긴 강의는 내용이 많아서 짧은 강의의 규칙(장 3–5개, 소절 12개 이하)을 그대로 쓰면 소절 하나가 너무 커지고,
반대로 슬라이드마다 소절을 만들면 목차가 50줄이 된다. 아래 순서로 정리한다. 예: `examples/geri_note.py`(노인정신질환 1, 136장).

## 1. 뼈대: 강의 자체의 목차를 장으로
- 교수님이 첫머리에서 말한 목차(“개론 → 평가 → 특징 → 각론 → 약물치료 → 정신치료”)를 그대로 장으로 쓴다. **장은 최대 6개.**
- 소절은 **장당 8개, 전체 20개 이하**(짧은 강의 6/12). 넘으면 같은 틀의 항목을 한 소절로 묶는다(예: 양극성장애 + 불안장애).
- 검사 `SECTION_TOO_MANY`가 `meta.long_lecture`를 보고 한도를 넓힌다. 장이 6개를 넘으면 `CHAPTER_TOO_MANY`.

## 2. 장 단위로 나눠 쓴다
- storyline.md도 노트도 **장 하나씩** 쓰고, 장을 끝낼 때마다 빌드해서 커버리지(빠진 ¶)와 쪽 수를 확인한다. 한 번에 136장을 다 쓰지 않는다.
- 장마다 대표 그림 1–2개(그래프, MRI, 검사 도구 그림). 글자뿐인 슬라이드는 그림으로 쓰지 않는다.

## 3. 같은 틀은 같은 꼴로 (표는 비교일 때만, L41)
- **절차·채점 세부**(예: MMSE 11개 항목)는 표가 아니라 ‘① **항목**: 방법, 채점 포인트’ 줄로.
- **질환 각론**처럼 같은 기준으로 여러 질환을 견주면 열을 맞춘 비교표(예: 불안장애 5종 `노인에서의 특징 | 감별, 치료`).
- 4대 부작용처럼 모두 중요한 항목을 견주는 목록은 표, 치료 기법처럼 각자 설명하는 목록은 ① 줄.

## 4. 반복되는 축은 한 번만 설명한다
- 긴 강의에는 같은 대비가 여러 장에 다시 나온다(예: 회상 vs 재인 — 신경심리검사, 정상 노화, 가성치매).
- 처음 나온 곳에 `[작성자가 헷갈려서 정리]` 상자로 한 번 정리하고, 뒤에서는 “앞의 Ⅱ-[4] 상자 참고”처럼 가리키기만 한다. **같은 사실은 최대 2번.**

## 5. 앞쪽 요약과 끝맺음
- 요약 ①: 전체 지도(장 → 소절 tree 도식) 1개 + 교수님이 “시험에 자주 나온다/국시/꼭 외워라”라고 한 곳을 모은 표(시험 축).
- 요약 ②: 반복되는 비교축 표 1개.
- Take home messages는 **장마다 1개 이상, 전체 7개 이하.**

## 6. 분량
- 목표 쪽수 ≈ 슬라이드 수 / 6 (136장 → 20–24쪽). 장 하나는 3–5쪽.
- 넘치면 줄이는 순서: 같은 사실 반복 → 그림 크기 → 회색 부연 → (내용은 줄이지 않는다).
