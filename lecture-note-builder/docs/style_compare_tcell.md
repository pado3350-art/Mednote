## 피드백 요약
1. 구성: MOM은 2부 6§(Part 1 MHC와 기능 §1~3, Part 2 unconventional T §1~3). 앞쪽 = 핵심 어휘 4개 → 도입 한 문단(감염원 입장) → 요약 정리 → 각 § 기본정석 3줄. 우리는 4장 11소절, 앞쪽 = 지도 + 기출 비교표.
2. 순서: MOM은 강의 순서대로 superantigen 뒤에 다양성 사례(EBV, 말라리아)와 ‘MHC가 많으면 더 좋을까?’를 두고 ‘강의 초반에 언급했었는데’로 되짚는다. 우리는 ¶32–33을 Ⅱ장으로 옮겨 ‘소절 순서 = 스크립트 ¶ 순서’ 원칙을 어겼다.
3. 묶는 틀: MOM은 CD1·FcRn을 ‘non-MHC encoded class 1b’(MHC 밖 염색체에서 만들어짐)로 묶어 왜 같이 보는지 알려 준다. 우리 스크립트에는 이 틀이 없다.
4. 출처: MOM은 교수님 표현, PPT 설명, 파드, 작성자 해석을 문장마다 구분한다(‘교수님의 표현에 따르면’, ‘PPT 설명에 의하면’, ‘(파드)’, ‘~라고 받아들이는 것이 맞을 것 같습니다’). 우리는 대부분 출처 없이 단정한다.
5. 연결: MOM은 앞 강의(CDR3, DM/DO), 다른 과목(이형접합, EBV)과 잇는다. 우리는 스크립트의 ‘앞 시간에’ 연결도 빠졌다.
6. 설명: MOM은 원인→결과 사슬로 푼다(negative selection이 강한 결합을 없앰 → 약한 결합만 남음 → 비슷한 타인 MHC에는 강한 반응). ‘즉, 결국’으로 매듭. 우리는 사실을 나란히 놓고 사슬이 짧다.
7. 문체: MOM 해라체 + 작성자 목소리(‘매우 유감스러운 상황이다’, ‘했대요’). 우리는 합니다체(L5 v2, 사용자 승인)로 균일하다. 문장은 우리가 짧고(45자) 고르다.
8. 우리가 나은 점: 스크립트 ¶ 근거 100%, 기출 파랑과 출처 일관, 비교표는 실제 비교만, 검증 필요 표시(CD1c/CD1d), 표지 강조점·Take home.

## 개선 후보 (승인 전, 규칙으로 저장하지 않음)
- T1 소절 순서 복원: 순서를 옮긴 소절은 원래 ¶ 자리로 되돌리고, 앞 내용과 잇는 되짚기 한 문장을 둔다.
- T2 출처 꼬리 표시: 교수님 표현 ‘(교수님 표현)’, 자료·PPT ‘(자료)’, 기출 ‘(파드)’, 작성자 해석은 괄호 합니다체.
- T3 앞 강의·다른 과목 연결 유지: 스크립트의 ‘앞 시간에’, ‘전에 배운’은 빼지 않는다.
- T4 기전 사슬 매듭: 인과가 있는 문단은 ‘즉/결국 A → B → C’로 한 번 묶는다(L12와 같은 방향).
- T5 묶는 틀 이름 붙이기: 여러 분자를 한 소절에 묶을 때 왜 묶는지(공통점) 첫 문장에 쓴다.
