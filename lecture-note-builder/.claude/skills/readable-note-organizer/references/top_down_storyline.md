# Top-down 작성: 흐름을 먼저, 문장은 나중에

문장을 쓰기 전에 **`{out}/storyline.md`를 먼저 완성한다.** 노트 JSON은 이 파일을 펼쳐 쓰는 것이다.
소절부터 쓰고 흐름을 나중에 맞추면(bottom-up) 같은 개념이 여러 곳에 흩어지고, 장 제목이 강의의 말이 아니게 되고, 앞쪽 요약이 넓고 얕아진다(근거: `outputs/abx/review_vs_MOM.md`).

## 1. 순서 (각 단계를 끝내고 다음으로)

| 단계 | 할 일 | 끝났다는 기준 |
|---|---|---|
| ① 뼈대 찾기 | 강의가 **스스로 가진 구조**를 순서의 근거로 찾는다(목차 이름이 아니라 순서 근거): 교수의 질문(“질문1, 질문2”), “첫째/둘째”, 슬라이드 제목, Part 1/2, 학습목표 순서 | 뼈대를 강의 속 표현 그대로 적었다. 없으면 “없음”이라 쓰고 ②에서 만든다 |
| ② 한 문장 요지 | 강의 전체를 한 문장으로 | 이 문장을 모르는 사람에게 읽혀도 강의가 무엇을 하는지 안다 |
| ③ 장 = 내용의 위계 + 주장 | 장 제목에 대상과 용어(제목만 읽어도 무슨 강의인지), 장마다 “이 장이 독자에게 남기는 한 문장” | 장 요지만 이어 읽으면 ②가 된다 |
| ④ 소절 = 질문과 한 줄 답 | 소절마다 질문, 한 줄 답, 모양(explain/list), 들어가는 ¶ | 한 줄 답만 이어 읽으면 강의 줄거리가 된다. 모든 ¶가 정확히 한 곳에 있다 |
| ⑤ 다리 | 소절 사이 “앞의 결론 → 다음 질문” 한 문장 | 다음 소절의 질문이 앞 소절의 결론에서 나온다 |
| ⑥ 반복되는 축 | 같은 개념이 두 번 나오면 **첫 등장과 재등장을 짝지어** 적는다 | 재등장 소절 첫 문장이 “앞에서 본 X를 이번에는 Y의 눈으로” |
| ⑦ 시험 축 | PAD 유형별로 어느 소절이 답하는지, 교수의 “시험 나왔다/중요하다” 순간이 어디인지 | 앞쪽 요약 = 시험 축 표 + 전체 지도 1장. 나머지 주제는 요약에 넣지 않는다 |
| ⑧ 그림 인벤토리 | 그림마다 “그림이 담은 사실”(색·모양이 아니라 내용)과 놓을 소절 | 그림 속 글(약물 목록, 수치, 축)이 본문 문장으로 옮겨져 있다 |
| ⑨ 중요도 | 교수가 강조한 곳 / 읽고 넘긴 곳 / 생략할 잡담 | 읽고 넘긴 곳에 `effort: 참고`, 잡담은 회색 메모 1줄 |

그다음에 문장을 쓴다(스킬 00b절 “한 번 읽고 이해되는 문장”). 다 쓴 뒤 **핵심 답 상자만 이어 읽기**와 **장 첫 문장만 이어 읽기**로 스토리라인과 맞는지 확인한다.

## 2. storyline.md 양식

```markdown
# 스토리라인: <강의 제목>

## ① 강의의 뼈대 (강의 속 표현 그대로)
- ...

## ② 한 문장 요지
...

## ③④⑤ 장과 소절
### 1장 <제목> — 장 요지: ...
| § | 질문 | 한 줄 답 | 모양 | ¶ | 다음으로 가는 다리 |
|---|---|---|---|---|---|

## ⑥ 반복되는 축
- <개념>: 첫 등장 §x (무엇으로) → 재등장 §y (무엇으로)

## ⑦ 시험 축
| PAD 유형 | 문항 | 답하는 § | 교수 언급 |
|---|---|---|---|

## ⑧ 그림 인벤토리
| 그림 | 담은 사실 (본문으로 옮길 것) | § |
|---|---|---|

## ⑨ 중요도
- 강조: ... / 읽고 넘김: ... / 생략: ...
```

## 3. 제목 규칙과 예시

**제목에는 대상과 의학 용어를 넣는다.** 제목만 읽어도 무슨 강의인지 알아야 한다.

| 나쁜 제목 (주어도 용어도 없음) | 좋은 제목 |
|---|---|
| 질문1: 무엇을 고를까 | 항균제 선택 원칙: 사용 목적, 감염 장기, 환자 맥락 |
| 질문2: 어떻게 줄까 | 항균제 용량, 용법, 투여 경로의 결정 |
| 같은 증상인데 환자에 따라 왜 약이 달라지나? | 획득 경로(community acquired, nosocomial)와 면역 상태(competent, compromised)는 항균제 선택을 어떻게 바꾸나? |
| 시간 의존성과 농도 의존성은 어떻게 다른가? | 시간 의존성과 농도 의존성 살균(PK/PD)은 용법을 어떻게 정하나? |

**장은 강의 내용의 위계로, 소절 순서는 스크립트 ¶ 순서로.** 교수의 질문(영상의 “질문1/질문2”)은 장의 이름이 아니라 순서의 근거이고, 본문 첫 문단에서 풀어 쓴다.

### 항균제(Clinical Therapeutics) 강의 — 전체 예시: `outputs/abx/storyline.md`
| 장 (내용의 위계) | 소절 (¶ 순서) | ¶ |
|---|---|---|
| 1. 항균제 선택 원칙: 사용 목적, 감염 장기, 환자 맥락 | 시작점 / 사용 목적 4가지 / 감염 장기 / 획득 경로 × 면역(4사분면) ⭐기출 | 1–17 |
| 2. 경험적 치료에서 표적 치료로: 치료 과정, 정균제와 살균제, 환자 인자 | 경험적 → 표적 / 정균제 vs 살균제 / 환자 인자 | 18–27 |
| 3. 항균제 용량, 용법, 투여 경로의 결정 | 용법의 근거 / 감염 기관별 경로 / 환자 사정별 경로 / 주사 vs 경구 | 28–39 |
| 4. PK/PD에 따른 용법, 투여 경로 원칙, 병용요법 | 시간 vs 농도 의존성 ⭐기출 / 경구가 기본 / 병용요법 | 40–52 |

- 이 강의의 뼈대(영상의 질문1, 질문2)는 1장과 3·4장에 대응한다. 중간의 치료 과정·환자 인자(¶18–27)는 2장으로 따로 묶어 스크립트 순서를 지켰다.
- 앞쪽 요약 = 기출 두 유형 표 + 4장 지도 1장.
- 그림 인벤토리, 반복되는 축, 시험 축, 중요도는 같은 파일 ⑥–⑨.
- 중요도는 스크립트에 근거가 있을 때만 쓴다(교수의 “시험 문제가 나왔다”(¶15), “이 슬라이드가 중요하다”(¶44), “실제 중요한 것들은 질문2에서”(¶51)). 사람 정리본의 평가를 옮겨 오지 않는다.
