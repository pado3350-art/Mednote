# 모범 예시에서 체득한 서술 기법 (Nucleotide Biosynthesis(2) MOM 분석 요약)

원본 PDF는 비공개라 저장하지 않는다. 전체 분석: `docs/nucleotide_example_analysis.md`.
**문체(합니다체·구어)는 가져오지 않는다 — 사용자 규칙은 한다체·교수님 인용 삭제(`my-writing-style`).** 가져온 것은 어미와 무관한 구조·기법이다.
**⛔ 파랑 = 기출(PAD) 전용은 예시에서 본 어떤 색 사용보다 우선한다.** 노력 수준·핵심 표시는 빨강/굵게/꼬리표로 하고 파랑으로 하지 않는다.

| 기법 | 노트에서 쓰는 법 |
|---|---|
| 3층 구조 | 서술 GUIDE(작성자 목소리 요약) → 시험 필수 → 본문 → QUIZ(해설 포함) |
| 쪽마다 개념 Check | `kind: check` (O/X + 정답 + 한 줄 요약). 같은 § 본문만으로 풀리게, 정답은 § 끝 정답 상자 |
| 노력 단서 | 문장 끝 `effort`: 필수(빨강) / 이해(검정) / 참고(회색). 스크립트의 “외울 필요 없다/시험에 나온다/참고만” 발화에서 근거 (`brief/effort_cues.md`) |
| 작성자 추가분 | `origin: author` → 회색 괄호. 비유·암기 팁·슬라이드 오류 정정에 쓴다. 사실 주장에는 쓰지 않는다 |
| 비유·의인화 | 기전마다 1개, 작성자 추가분으로 표시 (“5-FU는 스파이 — 효소가 uracil로 착각한다”) |
| 기전 표준형 | 번호 단계 1)–n) + 마무리 한 줄(“이렇게 n단계를 거쳐 …가 되었다. 남는 것은 …”) |
| 그림 지시 문장 | 그림 옆 문장이 그림 속 위치·색·화살표를 가리킨다 (“그림 우측 하단 화살표”) |
| 개념 정리 박스 | `kind: concept` — 용어 대비를 본문 뒤에 회색 박스로 한 번 더 |
| 퀴즈 해설 | `quiz.explanations`: 선지별 해설 + 정답 선지에 `(정답)` |
| 시간 간 연결 | “지난 시간에 본 …” — 이전 교시 정보가 있을 때만 |
