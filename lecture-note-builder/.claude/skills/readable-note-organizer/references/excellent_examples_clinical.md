# 우수 예시 3종 (임상 강의) — 구성·디자인·말투 정리

Extracted from three high-rated MOM notes (심혈관계 9교시 / 8교시, 정신 1-2교시). Use them as the reference for
**structure, visual vocabulary and the author's voice**. Quotes are short excerpts for style only.

## 1. 표지 / 코멘트 구성
- 이중선 제목 박스: `2025년 10월 30일 목요일 9교시 <심혈관계> 허성호 교수님` + 큰 제목.
- 작성자 코멘트(테두리 박스)에 들어가는 것:
  1. 이 노트가 어떻게 만들어졌는지 ("표나 박스에 강의 슬라이드(영어)를 그대로 담고, 교수님의 설명(한글)을 정리해서 덧붙였습니다.")
  2. 공부 전략 — 무엇을 먼저/가볍게 ("2쪽의 진단 기억하고, 치료는 파란색 위주로 외우고, 파드 보면서 심전도에 익숙해지면 탈로 나와도 푸실 수 있을 거라고 생각합니다!")
  3. 교수님·파드 정보 ("18-20학번에서 허성호 교수님이 담당하셨고, 허성호 교수님 파드 / 다른 교수님 파드로 표시했습니다.", "꼼꼼하게 설명은 하셨지만 생각보다 파란색이 적습니다.")
  4. 강의 성격과 주의 ("사실 시험에 나오는 내용은 다음 교시에 대부분 있는 것 같습니다. ACS 발생 기전과 분류에 대해서 후딱 보고 넘어가셔요", "반드시 PPT를 함께 보시기 바랍니다." — 빨강 굵게, 핵심 팁은 노란 형광펜)
  5. 색 범례(파랑=파드 / 초록=수정 / 빨강=강조 / 회색=중요도 낮음; 파드가 두 교수님이면 파랑·하늘색 두 가지)
- 목차(점선+쪽수), 학습목표 번호 목록(`1. …을 설명할 수 있다.`).
- 이전 교시에서 이어지면 목차 번호도 이어진다 (IV. … V. … VI.).

## 2. 본문 구성 요소
- **2단 슬라이드 표**: 왼쪽 = 슬라이드 원문(영어 그대로, 표·박스·캡처 이미지 포함), 오른쪽 = 교수님 설명(한글)을 ●로 정리, 강조는 빨강, 파드는 파랑/하늘색.
  `Clinical indicators of increased risk` 표처럼 항목별(History / ECG / Cardiac markers …) 행으로 나눈다.
- **소제목**: 로마자 대제목(`V. Risk Stratification`), 노란 마커 제목(`Definition and Classification`), 연한 파랑 띠 소제목(`(1) 조기중재 early intervention`).
- **QUIZ 박스**: 슬라이드의 사례(환자 한 줄 + 심전도 등 이미지) + 선지 → 박스 아래 풀이("고혈압, 당뇨, 흡연력이 있는 67세 남성 환자로 … 따라서 정답은 4번입니다.").
  영상이 잘렸으면 작성자가 풀이를 쓴다("영상이 잘려 풀이는 제가 쓰겠습니다.").
- **암기 틀**: `ABCDE` 접근법처럼 머리글자를 굵게(`**A**ntiplatelet …`). 순서·단계는 → 로 잇는다.
- **가이드라인 슬라이드**: "→ 결국 시험 정답은 이걸 기반으로 고릅니다." 같은 한 줄 연결.
- **금기/주의**는 빨강 굵게 + 느낌표("금기!", "UA/NSTEMI의 경우 해롭다고 했었죠!").
- 인라인 출처 표기: `(PAD: …)`, `교수님: … (강조??)`, `(재작야에는 7점이라고 하셨다네요)`.
- 회색 = 교수님이 읽기만 하고 넘어간/중요도 낮은 부분. 전부 읽어줬지만 기출·강조가 없으면 그대로 회색.
- 파드 표시는 맥락 속에 (파랑 글씨 문장 끝에 근거를 따로 붙이지 않아도 색이 곧 출처).

## 3. 말투 (작성자 = 같은 학년 학생, 후배·동기에게 말하는 톤)
| 문장 기능 | 어미 | 예 |
|---|---|---|
| 사실·정의·슬라이드 번역 | ~한다 / ~이다 / ~할 수 있다 | "TIMI 점수가 높을수록 14일 이내에 사망, 심근경색 … 발생 확률이 높아진다." |
| 교수님이 한 말·강조 | ~하셨다 / ~라고 합니다 / ~라고 하심 | "STEMI로 진단하려면 해부학적으로 인접한 두 개 이상의 유도에서 ST분절 상승이 나타나야 한다고 합니다." |
| 독자 안내·공부 조언 | ~하시면 됩니다 / ~해두시면 좋습니다 / ~하자 | "이걸 다 외울 필요는 없을 것 같습니다. 다음 쪽의 TIMI나 10쪽의 가이드라인이 훨씬 중요합니다." |
| 작성자 의견·불확실 | 괄호 + 솔직한 표현 | "(교수님께서 HLA-DM, DO는 MHC class 2가 아니라고 하셨는데, 정확하게는 classical MHC class 2가 아니라고 받아들이는 것이 맞을 것 같습니다.)" |
| 격려·마무리 | 짧게, 가볍게 | "화이팅입니다", "푸실 수 있을 거라고 생각합니다!", "후딱 보고 넘어가셔요" |
- 설명할 때는 직관 → 용어 → 숫자 순서. 숫자에는 의미를 붙인다("UA 사망률 1.7%, NSTEMI 5.1%로 약 3배 높다").
- 은어: 파드(PAD, 기출문제 모음) · 탈(기출 문제, "탈로 나와도") · 짤(재탕 문제) · 작야/재작야(작년/재작년) · 애플(PPT/교재 자료) · MOM(이 노트).
- 우선순위를 항상 말해 준다: "제일 중요!", "이쪽이 훨씬 중요합니다", "가볍게 읽어보아도 좋다", "이건 다 외울 필요는 없을 것 같습니다".
- 과장·농담은 거의 없고, 하더라도 한 번 ("교수님 짤이셨군요… 왜 떠나셨나요…").
