## 핵심 어휘 (excerpt)
"핵심 어휘를 알아보자. 어차피 뒤에 다시 다 나올 거기 때문에 가볍게 보고 가도 좋다."
- MHC polymorphism : MHC의 다형성. 개인별로 나타내는 유전적 차이에 대한 개념이라고 일단 알아두자.
- CD1 molecule : non-classical MHC이다.
- 동종이식편반응 : 다른 개체간에 이식했을 때 나타나는 면역 반응. Typical한 MHC-peptide가 일으키는 반응보다 훨씬 크게 일어난다. 따라서, 이런 반응을 억제하는 것이 중요하다.
- 초항원(superantigen) : 일반적인 MHC-peptide보다 훨씬 강력한 반응을 일으켜 toxic shock syndrome과 같은 것들을 일으킬 수 있다.

## 도입 (intuition first)
"감염원 입장에서는 MHC에 얹혀지는 것만 피하면 면역 반응을 회피할 수 있다. 그렇기에 1가지의 MHC밖에 없다면 감염원이 회피하기 쉬울 것이다. 그러나 실제로는 MHC는 한 종류만 있지 않고 여러 개의 gene으로 구성되어 있으며(polygenic), 같은 유전자지만 여러 type의 alleles가 있다(polymorphic). ... 결국 이번 장에서는 MHC gene이 polymorphic하고 polygenic한데, 얘들이 어떻게 organization되어 있는지를 알아보는 것이다."

## 요약 정리 (cheat-sheet)
Human MHC의 구조 — Chromosome 6번 / Class I : HLA A, B, C – 1개씩 / Class I region에 존재 : HLA E, F, G (얘네는 class 1b) / Class II : HLA DR, DP, DQ – 2개씩
Polymorphism & polygeny — Polymorphism : 유전자형으로 가능한 것이 엄청 많다! / Polygeny : 동시에 발현되는 유전자의 수가 많다! (공동우성) / Class I이 더 polymorphism이 크다 (I 안에서는 B>A>C, II 안에서는 DRB>DQB>DPB) / 다양성은 gene conversion으로 얻어진다
MHC restriction — T-cell : 자기 자신의 MHC에 국한된 반응. 즉 자기 MHC + 자기한테 맞는 peptide / 예외1) alloresponse / 예외2) Superantigen
Class 1b molecule — Class 1과 비슷하지만 unconventional T cell과 NK cell을 자극 / HLA-C (class 1에도 1b에도 속함) / HLA-E/F/G : NK cell inhibition / MICA/B / CD1c : lipid 항원 presentation -> NKT cell이 인지
