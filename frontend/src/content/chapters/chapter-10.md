# Chapter 10: 항고혈압제

## 핵심 개념

고혈압(hypertension)은 수축기 혈압 ≥130 mmHg 또는 이완기 혈압 ≥80 mmHg로 정의됩니다 (ACC/AHA 2017). 약물 치료는 심혈관 이환율과 사망률을 유의하게 감소시킵니다.

---

## 1. 혈압 조절 메커니즘

$$\text{혈압(BP)} = \text{심박출량(CO)} \times \text{말초혈관저항(SVR)}$$

항고혈압제는 CO 또는 SVR을 감소시켜 혈압을 낮춥니다.

---

## 2. 주요 항고혈압제 분류

### 2.1 이뇨제 (Diuretics) — 1차 선택약

| 종류 | 대표 약물 | 작용 부위 | 특이 부작용 |
|------|----------|----------|------------|
| 티아지드 | 히드로클로로티아지드 | 원위세뇨관 | 저칼륨혈증, 고뇨산혈증 |
| 루프 이뇨제 | 푸로세미드 | Henle 상행각 | 저칼륨혈증, 이독성 |
| 칼륨보존 | 스피로노락톤 | 집합관 | 고칼륨혈증, 여성형 유방 |

### 2.2 ACE 억제제 (ACE Inhibitors)

**작용 기전:** 안지오텐신 전환 효소 억제 → 안지오텐신 II 생성 차단 → 혈관 확장 + 알도스테론 분비 감소

- 대표 약물: **에날라프릴, 리시노프릴, 캅토프릴**
- 적응증: 고혈압, 심부전, 당뇨병성 신증 (신장 보호 효과)
- **금기:** 임신 (태아 신장 기형), 혈관부종 병력
- **부작용:** 마른 기침 (브라디키닌 축적), 혈관부종

### 2.3 안지오텐신 수용체 차단제 (ARB)

**작용 기전:** AT1 수용체 직접 차단 → ACE 억제제와 유사한 효과

- 대표 약물: **로사르탄, 발사르탄, 올메사르탄**
- ACE 억제제와 차이: **기침 부작용 없음** (브라디키닌 영향 없음)
- ACE 억제제 불내성 환자에서 대체 사용

> ⚠️ ACE 억제제 + ARB 병용은 신부전, 고칼륨혈증 위험으로 **금기**

### 2.4 칼슘 채널 차단제 (CCB)

| 종류 | 대표 약물 | 주요 효과 |
|------|----------|---------|
| 디하이드로피리딘 | 암로디핀, 니페디핀 | 혈관 확장 (SVR↓) |
| 비디하이드로피리딘 | 딜티아젬, 베라파밀 | 심박수↓ + 혈관 확장 |

- 디하이드로피리딘 CCB: 고혈압, 협심증
- 비디하이드로피리딘 CCB: 협심증, 부정맥 (특히 SVT)
- **부작용:** 말초 부종, 반사성 빈맥 (디하이드로피리딘)

### 2.5 β-차단제 (Beta-Blockers)

**작용 기전:** β1 수용체 차단 → 심박수↓, 심근 수축력↓ → CO 감소

| 선택성 | 약물 | 특징 |
|--------|------|------|
| β1 선택적 | 메토프롤롤, 아테놀롤 | 천식 환자에서 상대적으로 안전 |
| 비선택적 | 프로프라놀롤, 나돌롤 | 기관지수축 주의 |
| α+β 차단 | 카르베딜롤, 라베탈롤 | 심부전, 임신성 고혈압 |

- **금기:** 천식/COPD (비선택적), 고도 방실 차단
- **주의:** 갑작스러운 중단 시 반동 효과(rebound)

---

## 3. 강제적 적응증 (Compelling Indications)

| 동반 질환 | 1차 선택 약물 |
|---------|------------|
| 심부전 | ACE 억제제/ARB + β차단제 + 이뇨제 + 스피로노락톤 |
| 심근경색 후 | β차단제 + ACE 억제제 |
| 당뇨병성 신증 | ACE 억제제 또는 ARB |
| 뇌졸중 예방 | 티아지드 이뇨제 + ACE 억제제 |
| 임신성 고혈압 | 메틸도파, 히드랄라진, 라베탈롤 |

---

## 4. 병용 요법

단일 약제로 혈압 조절이 불충분한 경우 병용:

```
1차: ACE 억제제/ARB 또는 CCB 또는 티아지드
2차: 위 3가지 중 2가지 병용
3차: 위 3가지 모두 병용 (저항성 고혈압)
4차: 스피로노락톤 추가
```
